原型说明 · 侧边栏状态「今日工作台」

可交互：点 Tab 切换 / 勾选打卡 / 番茄预设与启停 / 拖上方滑块改变宽度 / 右上角切深浅主题

结构

  • 表头改称「今日工作台」，脱离/关闭按钮保留原位
  • 表头下新增 4 格图标 Tab：日程 · 打卡 · 番茄 · 导航，一次只显示一个工具，300px 窄栏也不拥挤
  • 原「今日打卡」段落移入打卡 Tab（消除两处重复）；原底部番茄状态条保留为全局条：运行中悬浮于任何 Tab，点击直达番茄 Tab

    • 各 Tab 要点

  • 日程：即现有内容（逾期 / 今日 / 快速添加），去掉打卡段后更聚焦
  • 打卡：顶部完成度圆环；「今日 / 统计」子切换 —— 今日为勾选列表（近 7 日迷你条 + 连击），统计为每习惯 2×2 指标卡（当前连续 / 最长连续 / 累计 / 近30天率 + 迷你进度条，弹性习惯显示本周 x/target）
  • 番茄：大数字倒计时 + 阶段徽章 + 预设分段器（15/25/45）；不含关联任务
  • 导航：搜索 + 分类 chips + 双列卡片（彩色字母 favicon + 域名），点卡片直接开浏览器

    • 实现备注（原型 ≠ 最终）

  • 底部番茄全局条仅运行中显示，暂停/结束即消失；显示期间点击直达番茄 Tab
  • 三个工具的数据层完全复用现有 IPC（bookmarkGetAll / habit / pomodoro context），只是视图瘦身
  • 「彻底移动」= 工具箱对应入口移除或保留跳转，待定后实施
