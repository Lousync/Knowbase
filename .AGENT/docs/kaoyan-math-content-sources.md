## 1. 插件形态回顾（408 插件是怎么做的）

市场条目（`registry.json`）参考：

```json
{

  "name": "408 学习空间",
  "version": "1.1.0",
  "category": "知识包",
  "riskLevel": "A",
  "contributions": ["knowledgePages"],
  "size": 29318623
}
```

内容组织：**四大教材笔记本（25 章 76 页，39 个分步动画 + 140 张 SVG 示意图）+ 历年真题（2009–2026 共 18 套，按年份成章、每科一页，答案解析折叠）**，安装后一键导入为独立学习空间。

### manifest（`contributes.knowledgePages`）格式约束

| 项 | 约束（`pluginRegistry.ts` 校验） |
|---|---|
| 结构 | v2 优先：`{ space, notebooks: [ { name, coverColor?, chapters: [ { name, pages: [ { file, title, externalId, tags? } ] } ] } ] }` |
| space | 字符串 ≤60 字符（空间名） |
| notebooks | 1–20 个，name ≤50 字符 |
| chapters | 1–50 个/笔记本，name ≤50 字符 |
| pages | 1–500 个/章节，file 为 `xxx.md` 相对路径，**全包页面总数 ≤1500** |
| 单页大小 | ≤512KB（`knowledgePackImporter.ts`） |
| 包体 | 内容型插件限额放宽至 60MB / 1500 文件 |
| 公式 | Markdown 内用 LaTeX（`$...$`/`$$...$$`），Monaco + KaTeX 已支持渲染 |
| 示意图 | 独立成段的 `<svg>` 会被剥离存为 `assets/extracted-N.svg` 并转为图片引用；SVG 内 script/事件属性会被清除 |

### 2.4 核心公式手册（笔记本 D，三卷通用）

> 数学公式本身不受版权保护，**公式手册是全包最安全、性价比最高的部分，建议优先做**。

### 2.5 历年真题（笔记本 E）

408 做法：**按年份成章、每科一页、答案解析折叠**。数学建议：

- 每套真题 = 1 章（如 `2025 年数学一真题`），页 = 试卷 + 解析（或每题一页做错题本式整理）
- 卷种标注：数一/数二/数三 分开成章，避免混淆
- 规模建议：近 10 年（2016–2025）× 3 卷 = 30 套起步；全量 1987–2025 卷数过大，可放精选

### 2.6 可选的差异化内容（提高插件价值）

- **考纲对照表**：数一/二/三 考点差异速查（上面的表格即可成页）
- **题型攻略**：选择/填空/解答（含证明题）的答题策略（分值：10×5 + 6×5 + 6 大题共 70 分，满分 150）
- **高频考点 Top 榜**：真题重复率高的考点（中值定理证明、二重积分计算、矩阵秩、随机变量分布等）

## 4. 版权与合规注意（重点）

1. **教材与辅导书内容不能直接复制** —— 只能作为编写依据，文字需自行组织。
2. **真题转写**：题目文本用于本地免费学习工具属学习交流范畴，但建议在插件说明页声明"真题版权归命题单位所有，仅供学习交流"，参照开源真题库的做法。
3. **开源笔记搬运**：
   - Apache-2.0（ricolxwz）→ 可自由改编，保留许可证声明即可
   - CC BY-NC-SA（TsekaLuk、Origami404）→ 可改编，**不可商用，需署名 + 衍生作品同许可**；Knowbase 本地免费工具非商用，可行，但知识包文档页需附来源与许可
   - 未标注许可证的仓库 → 默认保留版权，**不搬内容**，只借鉴结构与思路
4. **数学公式**：数学公式本身不受版权保护，公式手册可放心编写。
5. **推荐组合**：公式手册（自撰）+ 各科知识点（以教材/开源 Apache 笔记为底稿自撰）+ 真题（转写开源 CC 真题库 + 声明版权）。

## 5. 开发路线建议

1. **搭骨架**：建插件目录 + `manifest.json`（`contributes.knowledgePages` v2 结构）+ 图标；registry 条目 `category: 知识包`、`riskLevel: A`
2. **公式手册优先**（笔记本 D）：安全、快、通用价值高
3. **高数 → 线代 → 概率** 知识点页：参考开源笔记组织，自行撰写；注意数一/二/三差异页标注
4. **真题**：从开源 Markdown 真题库转写近 10 年三卷（2016–2025），答案解析折叠
5. **SVG 示意图**：408 用了 140 张；数学建议给函数图像、几何直观、定理关系图（如四大中值定理关系）配图
6. **规模目标**：参照 408 的 25 章 76 页起步，数学可做到 3 科 × 6–9 章 + 公式册 + 真题，控制在 1500 页/60MB 限额内
7. 完成后按贡献指南打包 zip → 放入 `plugins/<plugin-id>/` → 更新 `registry.json` + `CHANGELOG.md` → PR
