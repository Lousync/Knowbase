## 2. 考试结构速览（2026 大纲）

### 2.1 试卷结构（满分 100，180 分钟，闭卷笔试）

| 题型 | 题量 | 分值 | 说明 |
|---|---|---|---|
| 单项选择题 | 16 题 | 16 分（每题 1 分） | 基础识记，相对简单 |
| 多项选择题 | 17 题 | 34 分（每题 2 分） | **拉分关键**：多选、少选、错选均不得分 |
| 材料分析题 | 5 题 | 50 分（每题 10 分） | 34–38 题，结合材料分析 |

> 结论：多选 + 分析题共 84 分。想上 70 分，选择题需 35–40 分。

### 2.2 内容结构（六大模块，大纲原文占比）

| 模块 | 占比 | 核心内容 |

| 毛泽东思想和中国特色社会主义理论体系概论（毛中特） | 约 13% | 毛泽东思想、邓理论、三个代表、科学发展观 |

### 2.4 2026 命题趋势（对知识包内容组织有直接指导意义）

- **时政融合**：时政考查比重从往年 28% 升至 42%；选择题 50 分中约 30 分涉及时政，分析题 50 分中约 40 分涉及时政（合计 80 分与时政相关）
- **反押题、反套路**：从"知识记忆"转向"知识运用"，材料分析占比提升至 72%
- **新思想独立成线**：不再是毛中特的一章，而是贯穿多模块的核心线索
- **马原考应用**：哲学原理需配现实案例理解；政经比重上升

## 3. 知识包结构规划（建议骨架）

空间名：**《考研政治》**，按"六大学科笔记本 + 刷题 + 背诵 + 真题"组织（约 180–220 页，远低于 1500 页限额）。

### 3.1 六大学科笔记本（A–F，知识点正文）

| 笔记本 | 章节规划 | 预估页数 |
|---|---|---|
| **A 马原** | 导论 → 世界的物质性及发展规律 → 实践与认识 → 人类社会及其发展规律 → 资本主义的本质及规律 → 资本主义的发展及其趋势 → 社会主义的发展及其规律 → 共产主义崇高理想（8 章，对齐 2023 教材） | 18–22 |
| **B 毛中特** | 导论 → 毛泽东思想及其历史地位 → 新民主主义革命理论 → 社会主义改造理论 → 社会主义建设道路初步探索 → 中特理论体系形成发展 → 邓小平理论 → 三个代表 → 科学发展观（9 章） | 12–15 |
| **C 新思想** | 导论 → 新时代坚持和发展中国特色社会主义 → 中国式现代化 → 高质量发展/新发展格局 → 全过程人民民主 → 文化自信 → 民生保障/共同富裕 → 生态文明 → 国家安全 → 强军/一国两制/大国外交 → 党的建设（按 2023 教材 17 章精选 10–12 章） | 20–25 |
| **D 史纲** | 旧民主主义革命（1840–1919）→ 新民主主义革命（1919–1949）→ 社会主义革命与建设（1949–1978）→ 改革开放与新时代（1978–今），配**时间轴总览页** | 14–18 |
| **E 思修法基** | 理想信念 → 中国精神 → 社会主义核心价值观 → 道德 → 法律基础（法治思想、宪法、民法典要点） | 10–12 |
| **F 形策与当代** | 年度时政专题（见 3.2）+ 当代世界经济与政治（多极化、全球化、全球治理、人类命运共同体） | 15–20 |

> 学科页注意：**知识点事实（理论表述、会议、时间、提法）属公共知识可自撰整理**；教材正文文字不能整段复制（详见第 5 节版权）。

### 3.2 时政专题（笔记本 F 的前置章节，标注"2026 版"）

2026 年度核心时政线索（命题热度高 → 中），来自公开权威报道：

| 专题 | 热度 | 关联模块 |
|---|---|---|
| "十五五"规划与二十届四中全会精神（2025-10 全会通过规划《建议》；2026-03 全国人大批准规划纲要 + 《国家发展规划法》） | 极高 | 毛中特/新思想、马原、当代 |
| 2026 世界人工智能大会（2026-07 上海，全球人工智能治理） | 极高 | 新思想、当代 |
| 新质生产力与高质量发展（贯穿全年） | 极高 | 新思想、马原（生产力与生产关系） |
| 生态文明与"十五五"碳达峰行动方案（2026-07 印发） | 高 | 新思想 |
| 全球发展倡议 5 周年（2026-07 高级别会议） | 中高 | 当代 |
| 大国外交与全球治理（人类命运共同体、三大全球倡议、真正多边主义） | 中高 | 当代 |

> 时政模块**每年必须更新**，知识包以"2026 版"发布；可考虑把时政做成独立小包便于单独升级（见待拍板事项）。

### 3.3 刷题笔记本（G，选择题题库 · 复用 quiz 围栏）

政治选择题（单选 16 + 多选 17）天然适合 408 已落地的判题模式：

- **章节同步练习**：按六科章节出题，每章 10–20 题（单选 + 多选），覆盖高频考点
- **易错/帽子题专题**：帽子题（"根本/基本/核心/前提"对应提法）、关键词陷阱、偷换概念类
- **真题选择题**：2024–2026 三年真题选择题（新大纲结构），按年成章
- 每题用 ` ```quiz ` 围栏（题干 + A/B/C/D + `> 答案` + `> 解析`），导入即得判题 + 错题能力

### 3.4 背诵手册笔记本（H，政治差异化亮点）

政治是最"背"的科目，背诵类页面性价比最高：

- **史纲时间轴**：1840 → 2026 大事记总览（核心锚点：1840 战争开端 / 1911 辛亥 / 1919 五四 / 1921 建党 / 1937 全面抗战 / 1945 胜利 / 1949 建国 / 1956 制度确立 / 1978 改革开放）
- **重要会议总结表**：一大→二十大"功能标签"（一大建党、二大立纲、三大合作、四大领导权、七大确立毛思想、遵义转折、十一届三中全会改革开放……）
- **土地政策演变表**：1928 井冈山《土地法》→ 1929 兴国《土地法》→ 1931 限制富农 → 1947《中国土地法大纲》→ 1950《土地改革法》（"没收一切→区别对待→废除剥削"脉络）
- **毛泽东重要著作速查**：时间 + 首次提出概念（《反对本本主义》思想路线、《共产党人发刊词》三大法宝、《论联合政府》三大作风……）
- **高频考点 Top 榜**：从真题重复率整理（哲学基本问题、矛盾普遍性与特殊性、剩余价值、新质生产力、中国式现代化五大特征、文化自信、人类命运共同体）
- **背诵口诀**：自撰顺口溜（注意：网上流传口诀来源杂、无许可证，只可参考其"口诀化"思路，不能直接搬运）

### 3.5 分析题模板笔记本（I，答题框架）

- **"点-析-结"三段框架**：点明原理 → 结合材料分析 → 总结升华（政治分析题通用结构）
- **五科模板各 1–2 页**：马原（原理 + 方法论）、毛中特/新思想（理论 + 政策 + 路径）、史纲（性质 + 意义 + 启示）、思修（价值 + 践行）、当代（主张 + 倡议 + 中国方案）
- **历年分析题真题 + 参考答案**：34–38 题结构标注（放真题笔记本或并入模板本，二选一）

### 3.6 历年真题笔记本（J）

- **建议范围**：2024–2026（**新大纲结构**，2024 起为现行六大模块布局）共 3 套 × 2 页（试卷 + 解析）；如需扩充可加 2022–2023（旧结构，标注"旧大纲，仅参考"）
- 每套 = 1 章，页 = 试卷 / 参考答案（分析题答案用 spoiler-answer 折叠）
- 真题文本来源：开源转写库 / 回忆版（见 4.3），并声明"真题版权归命题单位"

> **本轮调研补充结论（2026-08-29 实测）**：考研政治知识点素材**远比预期充足**——辅导生态成熟，五科笔记、教材课件、复习提纲全网公开可得。且政治考点本质是**官方规范话语**（帽子提法/关键词/标准表述，属公共知识公开可查），"自撰"=归纳官方表述成结构化页面，**几乎无原创表达障碍**，比数学更顺。素材分级：①官方公开内容（大纲/教材/文件/讲话）→ 可直接引用规范表述并标注出处（知识包主体来源）；②公开整理笔记/提纲 → 参考结构、重组文字；③商业机构笔记（徐涛/肖秀荣等）→ 只学方法不抄文字。

> 经验：政治开源生态远不如数学（数学有 Apache-2.0 的完整笔记，政治多为 CC BY-NC-SA 的 xmind/PDF 或未标注许可证），**大部分内容需要自撰**，开源底稿主要提供骨架与组织方式。

## 5. 版权与合规注意（重点）

1. **教材与辅导书内容不能直接复制** —— 只能作为编写依据，文字需自行组织。
2. **知识包主体应为自撰整理**：政治考点（会议、时间、理论提法、政策表述）本身是公共知识，自行归纳表述即可；这是政治知识包与数学（公式安全区）最大的不同——**没有"公式手册"式安全区，更需要全部自撰或基于开源底稿改写**。
3. **真题转写**：题目文本用于本地免费学习工具属学习交流范畴，插件说明页声明"真题版权归命题单位所有，仅供学习交流"。
4. **开源笔记搬运**：
   - CC BY-NC-SA（yishen 等）→ 可改编，**不可商用，需署名 + 衍生作品同许可**；Knowbase 本地免费工具非商用，可行，但知识包文档页需附来源与许可
   - 未标注许可证的仓库/分享 → 默认保留版权，**不搬内容**，只借鉴结构与思路
5. **机构押题/模拟卷表述不可收录**：肖四/肖八/小黄书等的具体"押题表述"受版权与商业价值双重保护，知识包只做"考点方向归纳"，不做原文搬运。
6. **时政内容**：官方文件与讲话属公开发布内容，引用规范表述需标注出处；避免整篇转载评论文章。
7. **推荐组合**：自撰六科知识点（以大纲 + 教材为纲，参考开源骨架）＋ 自撰刷题库（按考纲知识点出题）＋ 转写真题（声明版权）＋ 时政专题（官方来源归纳）。

## 6. 开发路线建议

1. **搭骨架**：插件目录 + `manifest.json`（v2 knowledgePages 结构）+ 图标；registry 条目 `category: 知识包`、`riskLevel: A`
2. **背诵手册优先**（笔记本 H）：时间轴/会议表/土地政策表/著作速查——全是公共知识表格，安全、快、政治特色最浓
3. **六科知识点页**：按"大纲标题骨架 → 自撰填充"推进，马原 → 史纲 → 思修 → 毛中特 → 新思想（新思想教材章节多，可先做高频章节）
4. **刷题库**（笔记本 G）：配合 408 已落地的 `quiz` 围栏判题模式，章节题 + 帽子题专题 + 真题选择题
5. **分析题模板**（笔记本 I）：点-析-结框架 + 五科模板 + 近三年真题参考答案
6. **时政专题**（笔记本 F）：发布时标注"2026 版"，内容以官方通稿为准
7. **真题**：2024–2026 三套（新大纲结构），试卷 + 解析分离页
8. **规模目标**：180–220 页 / 数十张表格，远低于 1500 页 / 60MB 限额；SVG 示意图可用于马原哲学关系图、史纲时间轴可视化
9. 完成后按贡献指南打包 zip → `plugins/<plugin-id>/` → 更新 `registry.json` + `CHANGELOG.md` → PR
