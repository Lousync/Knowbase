# 408 知识包 v1.2 · 选择题快速刷题判题模式（方案）

> 状态：**已实施（2026-08-29）** · 应用侧功能，旧 408 插件无需更新，已导入页面自动获得刷题能力
> 日期：2026-08-29 · 适用：408 知识包（`knowbase.kb-408-pack`）及未来考研数学/英语/政治知识包

---

## 1. 需求

用户痛点：408 真题页面目前是"看题 → 手动点开答案"的被动模式。希望升级为**刷题模式**：

- 选择题点选选项后**立即判题**
- **答对 → 自动过掉**（自动进入下一题）
- **答错 → 显示答案与解析**

## 2. 现状盘点（已核实代码）

| 现状 | 说明 |
|---|---|
| 渲染链路 | `MarkdownPreview`（react-markdown + remark-gfm/math + rehype-highlight/katex），组件级自定义能力已成熟 |
| 已有先例 | ```spoiler-answer 围栏 → `SpoilerBlock` 折叠组件（答案/解析默认收起，内部走完整 Markdown 管线含公式/图片） |
| 408 真题格式 | 选择题题干/选项/答案/解析齐全，答案与解析放 spoiler-answer 块；121 张题图附件化（attachment://）；18 套 846 题已在用户库中 |
| 阅读入口 | 知识库沉浸阅读（`readingMode`）用 MarkdownPreview；知识包导入后为普通页面 |

**关键结论**：判题所需的全部数据（题干、选项、答案、解析）**已经在页面内容里**，无需改数据库、无需新 IPC、无需迁移。纯渲染层增量即可实现。

## 3. 方案总览（两层，可分步交付）

### 3.1 v1：页面内判题卡片（推荐先做）

打开真题页，每道选择题直接渲染为**可交互判题卡片**：

```
┌─────────────────────────────────────┐
│ 1. 设 f(x) 在 [0,1] 上连续，则…（ ）      │
│  A. 选项一          B. 选项二             │
│  C. 选项三          D. 选项四             │
│   [点选 → 立即判题]                        │
│   答对：选项变绿 ✓ 自动滚动到下一题           │
│   答错：选项变红 ✗ 正确答案高亮绿 + 展开解析   │
└─────────────────────────────────────┘
```

- **判题逻辑**：点选项 → 对则绿 + 自动滚动/聚焦下一题；错则红 + 正确项绿 + 自动展开解析（内部复用 spoiler 渲染管线，公式/图片全支持）
- **答题状态**：组件 state（本页会话内），可选用 localStorage 按 `页面ID+题号` 记住对/错/当前进度
- **键盘**：`1-4` 或 `A-D` 直接作答（卡片聚焦时）

### 3.2 v2：沉浸刷题模式（进阶）

知识库页面工具栏加「刷题模式」按钮，进入**逐题全屏模式**：

- 一题一屏，题干 + 选项 + 大按钮
- 答对自动下一题（不打断节奏）；答错展示解析，手动/Enter 下一题
- 结束后：得分 / 用时 / 错题清单（可回看错题解析）
- 键盘全程操作（1-4 作答、Enter 下一题、Esc 退出）
- 与现有沉浸阅读（Ctrl+Shift+R）互不干扰

## 4. 内容识别：双轨解析（关键设计）

旧内容不能要求重做，所以**兼容两种来源**：

| 来源 | 格式 | 解析方式 |
|---|---|---|
| **旧 408 内容（已有 846 题）** | 编号题 + A/B/C/D 选项 + ```spoiler-answer 块（内含【答案】X 【解析】…） | **兼容解析**：识别"题目+选项"结构，从 spoiler 块内提取【答案】/【解析】生成判题卡片；不匹配时保持现状（普通折叠） |
| **新内容规范写法（推荐）** | 新增 ```quiz 围栏，结构化字段 | 严格解析，字段齐全，未来数学/英语/政治知识包统一用此格式 |

```markdown
```quiz
1. 设 $f(x)$ 在 $[0,1]$ 上连续，则下列命题正确的是（　）

A. $f(x)$ 在 $(0,1)$ 内必有零点
B. $f(x)$ 在 $(0,1)$ 内必有极值点
C. ...
D. ...

> 答案: B
> 解析: 由连续函数介值性可知……（支持 Markdown / $LaTeX$ / 图片）
```
```

**解析器要点**：
- 逐行解析：题干（数字. 开头）、选项（A. / A) / - A. 等变体）、答案（【答案】X 或 `答案: X`）
- 多选支持（答案可含多个字母，如"答案: AB"）
- 图题（attachment:// 图片）天然支持，图片在题干/选项/解析中均可
- 无法识别的块**静默降级**为普通文本/折叠块，绝不破坏现有渲染

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 旧 408 内容的题目/选项格式与我推断有出入（下载不了 zip 核实） | ①解析器做多变体兼容 ②**需要用户在应用里导出 1-2 页真题 markdown 给我校准**（关键依赖） |
| 页面内联模式下"自动过掉"的滚动体验 | v1 答对后滚动到下一题并聚焦；若页面题目过多（每页 10 题），滚动即"过掉"的观感基本等效 |
| Esc/快捷键冲突 | QuizMode 退出逻辑与沉浸阅读错开（不同入口）；卡片模式不劫持全局键 |
| 降级安全 | 解析失败一律退回普通渲染，不影响阅读与折叠功能 |

## 9. 实施记录（2026-08-29 已完成）

**新增文件**：

**验证**：
