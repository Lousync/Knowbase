一句话说明 LRU 和 FIFO 的区别

FIFO 淘汰最早进来的，LRU 淘汰最久没被用过的——前者的依据是"进入时间"，后者是"访问时间"。

所以 FIFO 可能出现"刚被频繁访问的页恰好最早进来"而被误淘汰，LRU 则不会。

十分钟写出第一篇笔记

读完能独立完成：新建 → 写正文 → 在知识库看到它

1. 选一个仓库。仓库就是磁盘上的一个普通文件夹，所有笔记都是里面的 .md 文件。随时可以换，也可以建多个。

2. 新建文件。在编辑区左侧文件树点 +，或按 Ctrl+N。写正文，停手一秒即自动保存。

3. 让它进知识库。知识库只收录带 frontmatter id 的文件：

--- id: my-first-note title: 我的第一篇笔记 ---

4. 连起来。用 #标签 分类，用 [[双链]] 指向其它页面，在「知识网络」里看它们连成网。

读写分工：编辑区是唯一能写正文的地方，知识库只负责阅读与组织。记住这一句，后面 90% 的困惑都会消失。
