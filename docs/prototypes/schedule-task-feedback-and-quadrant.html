1勾选完成的反馈感

现状：点击勾选 → 等 IPC 往返 → 整表 refreshAll 重排，条目直接从待办区消失，切换动画只有变色，所以"点下去没有反应"。
下面三档都建立在同一个前提上：乐观更新——点击瞬间本地先置为完成并立刻播放动画，数据落盘在后台跑（失败再回滚）。这是反馈感的地基。

2四象限标签 · 紧迫感图标

现状是四个纯文字按钮（紧急重要 / 重要不紧急 / 紧急不重要 / 不紧急不重要），彼此只有颜色差别。
图标语言统一为「紧迫度档位 n」，n 越大越紧迫；按钮可切换、可对比 hover / 选中态。

排序：为什么用紧迫阶梯已采用
保持现状（紧急重要 → 重要不紧急 → 紧急不重要 → 不紧急不重要）的紧迫档位是 4 · 2 · 3 · 1，图标高低跳来跳去，"阶梯"读不出来。
按紧迫阶梯重排（不紧急不重要 → 重要不紧急 → 紧急不重要 → 紧急重要）得到 1 · 2 · 3 · 4，从左到右一路升高，是一条朝右上走的阶梯。
底层 quadrant 值 0/1/2/3 与数据结构不动，只是渲染顺序变了（数组重排即可），零迁移成本。
