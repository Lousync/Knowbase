# Workbench 化布局设计

> 归属：[rework-master-plan.md](./rework-master-plan.md) D4 / R1 阶段。状态：设计定稿，未实现。
> 交互原型已在 2026-09-02 会话内演示（活动栏/侧栏/编辑器组/底部面板联动）。

## 1. 布局五区

```
┌─────────────────────────────────────────────────────┐
│ 标题栏（现有自绘标题栏保留，增加布局开关按钮）              │
├────┬──────────┬──────────────────────────┬──────────┤
│ 活  │ 侧栏      │ 编辑器组（Tab 栏 + 内容区）  │          │
│ 动  │ (内容随   │  ┌────────────────────┐  │  (预留    │
│ 栏  │  活动栏   │  │ Monaco / CM6 / 图谱 │  │  右侧栏)  │
│ 42px│  切换)    │  └────────────────────┘  │          │
│    │ 160-220px │ 底部面板（搜索/日志，可收起） │          │
├────┴──────────┴──────────────────────────┴──────────┤
│ 状态栏：当前仓库 · 番茄钟 · 快捷键提示                     │
└─────────────────────────────────────────────────────┘
```

- **活动栏**：图标化模块入口，42px 宽，可整体折叠（Ctrl+B 折叠侧栏+活动栏收窄）。对齐用户偏好：极简、无文字标签、hover 出 tooltip
- **侧栏**：内容 = 当前激活活动栏图标的「模块视图」（见 §2 映射）；宽度可拖拽，记忆 per 仓库
- **编辑器组**：唯一写入区。v1 单组，Editor Groups 分屏为 R2 目标（同屏 ≤3 组）
- **底部面板**：全局搜索结果、AI 工具审计日志、后续可挂迁移进度；Ctrl+` 开关
- **状态栏**：仓库上下文（路径/账户名）、番茄钟常驻、后台任务（索引重建/更新下载进度）

## 2. 模块 → Workbench 映射（核心迁移表）

| 模块 | 现形态（整页 Tab） | Workbench 形态 | 改造量 |
|---|---|---|---|
| 编辑器 | 整页 Tab | **编辑器组主体**（Tab 栏 + Monaco） | 低（现 openFiles 文档模型即编辑器组雏形） |
| 知识库 | 整页 | 侧栏 = 空间/笔记本树 + 标签/收藏；编辑器组 = 阅读视图（MarkdownPreview + 反链面板）；图谱视图挂阅读区 | 中（重设计进行中，协同） |
| 博客 | 整页 | 侧栏 = 日历 + 文章列表；编辑器组 = 文章阅读/模板预览 | 中 |
| 任务 | 整页 | 侧栏 = 今日/四象限摘要；编辑器组 = 日历视图 | 中 |
| 说说 | 整页 | 侧栏 = 时间线；编辑器组 = 相册/详情 | 低 |
| AI 助手 | 全局侧栏 Ctrl+J | 保留现有悬浮侧栏（右侧），另在活动栏加入口 | 低 |
| 插件 | 整页 | 侧栏 = 已装列表；编辑器组 = 插件详情/市场 | 低 |
| 工具箱 | 整页 | 侧栏 = 工具列表；编辑器组 = 具体工具 | 低 |
| 回收站/帮助/设置/用户 | 整页 | 编辑器组以 Tab 打开（非侧栏） | 低 |
| 日程小窗 | 独立窗口 | 不变 | 无 |

**原则**：模块的「导航/列表」进侧栏，「内容/操作面」进编辑器组。模块保活架构（首次挂载后 `display:none` 常驻）沿用，只是挂载点从根容器改为侧栏/编辑器槽位。

## 3. 命令面板 + 快速切换器（随 R1 一起做）

- `Ctrl+Shift+P` 命令面板：命令来源 = 各模块注册（新建/跳转/开关视图）+ 设置项 + 插件命令（R7 预留注册接口）
- `Ctrl+O` 快速切换器：基于 knowledgeIndex 文件名/标题模糊匹配，Enter 在编辑器组打开
- 二者共用同一悬浮层组件，数据源不同
- 现有模块级快捷键迁移：按激活模块过滤的约定保留

## 4. App.tsx 改造面（风险最大单点）

1. 根容器从「TitleBar + ActivityBar + 整页模块」改为「TitleBar + Workbench 槽位（活动栏/侧栏/编辑器组/面板/状态栏）」
2. `renderTab` 拆为 `renderSidebarView(moduleId)` 与 `renderEditorView(...)` 两类挂载
3. 模块保活：槽位级保活（sidebar kept-alive 与 editor kept-alive 两个常驻容器）
4. 灰度策略：加设置开关 `ui.workbench: boolean`，默认旧布局，Workbench 稳定后切默认——与数据层双读源开关同一套灰度思路
5. Tailwind v4 注意：过渡属性用 `translate` 不用 `transform`（历史坑）
