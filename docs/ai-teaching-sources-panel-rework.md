# AI 教学 · 右栏素材库改造（多素材场景 + 收起动画）

> 状态：✅ 已实现（2026-09-09）· 方案定稿（2026-09-09 用户确认满意）
> 原型：`docs/prototypes/ai-teaching-sources-collapse.html`（可交互，25 条假数据）
> 关联：`docs/ai-teaching-module-rework.md` P6 素材库（§3.13 结构 v3）

## 1. 背景与问题

素材库条目增长后（20+ 条），现状布局暴露三个结构性问题（依据 `src/modules/ai-teaching/index.tsx` L2091-2237）：

| # | 问题 | 根因 |
|---|------|------|
| 1 | **一锅滚**：「本次改动」「视觉转写进度卡」被素材列表推出首屏；转写中要滚到列表底部才能点「停止」 | 右栏容器整栏一条 `overflow-y-auto`（L2096），素材区与「本次改动」均为 `shrink-0` 自然增高，无 max-h、无内部滚动 |
| 2 | **找条目靠肉眼**：pdf/pptx/url/code/dir 五类混排单列平铺，无分组、无折叠、无过滤 | `srcEntries.map` 平铺渲染（L2135） |
| 3 | **卡片行内挤压**：单条 pdf 条目可同时出现 4-5 个文字操作按钮（提取稿✓/提取/转写/再加区间/原件/✕），280px 默认宽度下互相挤压 | 操作组 `ml-auto flex gap-1.5` 不换行（L2150） |

隐性成本（本改造不解决，挂账观察）：SOURCE.md 每轮全量注入对话（L45），素材条目越多 token 线性增长。

## 2. 方案定稿

候选方案取舍：

| 方案 | 内容 | Verdict |
|------|------|---------|
| A. 区块内部滚动 | 素材列表 max-h + 自滚动，「本次改动」固定可见 | ✅ 采纳 |
| B. 类型分组 + 过滤 chips | 按类型分组折叠，顶部类型筛选 | ✅ 采纳 |
| C. 操作收敛「⋯」菜单 | 行内只留高频动作，其余进菜单 | 🔶 缓做（加一次点击成本，先观察挤压实际频率） |
| D. 转写进度钉底 | 进度卡固定右栏底部，不随列表滚 | ✅ 采纳 |

### 2.1 新布局结构

```
右栏 ResizablePanel（240–420px，storageKey=aiTeach.rightWidth，不变）
├─ 面板头：素材库（N）｜ SOURCE ｜ ＋素材 ｜ 收起卡片(新)
├─ 过滤 chips：全部 / PDF / PPT / 网页 / 代码 / 目录（新）
├─ 素材列表 ← flex-1 min-h-0 overflow-y-auto（内部滚动，方案 A）
│   ├─ 分组：PDF 文件 / PPT 课件 / 网页 / 代码 / 目录（方案 B）
│   │   └─ 组头：箭头 + 色点 + 名称 + 计数徽标；点击折叠/展开
│   │   └─ 卡片：两行（#编号+名称+类型徽标 / 区间+存储+操作组），与现状一致
│   └─ 空组自动隐藏；过滤后无条目 → 空态提示
└─ 钉底区（shrink-0，永不被推走，方案 D）
    ├─ 转写进度卡（visionBusy 时显示，含停止按钮）
    └─ 本次改动（max-h-40 内部滚动，现状已有）
```

### 2.2 交互规格

- **分组折叠**：点组头切换；折叠状态建议持久化（`localStorage: aiTeach.srcGroupClosed`，JSON 数组）
- **紧凑收起**：顶栏「收起卡片」全局开关——所有卡片第二行收起、padding 收窄为单行细条；状态持久化（`aiTeach.srcCompact`）
- **过滤**：chips 单选；过滤只影响列表渲染，不影响 SOURCE.md 与 AI 注入
- **卡片操作**：本期不动（C 缓做）；按钮语义/ Confirm 流程保持现状（移除登记=不删文件等）

## 3. 收起动画规格

| 项 | 取值 | 理由 |
|----|------|------|
| 缓动曲线 | `cubic-bezier(0.22, 0.68, 0.32, 1)` | 快出缓停、无回弹——列表场景回弹显噪 |
| 分组体 | `grid-template-rows 1fr↔0fr`，360ms | 与项目内折叠区同思路（如左栏 `grid-template-rows` 折叠），无需 JS 测高 |
| 卡片淡出 | `opacity→0 + translateX(6px)`，300ms，随组体同步内收 | **不逐张排队**：25 张卡逐张 delay 会拖到 1s+，反而显慢 |
| 箭头旋转 | `rotate(-90°)`，260ms | 层级递减，细节先停 |
| 紧凑收起 | 卡片第二行 `0fr` + padding 收窄，260-320ms | 只动 grid-rows 与 padding，GPU 友好无布局抖动 |
| reduced-motion | `prefers-reduced-motion` 下时长归零 | 可访问性兜底 |

## 4. 落地改动点

全部集中在 `src/modules/ai-teaching/index.tsx` 右栏渲染段（L2091-2237）：

1. 容器拆分：外层改 `flex flex-col min-h-0`；素材列表独立 `flex-1 min-h-0 overflow-y-auto`；「本次改动」与转写进度卡移入钉底 `shrink-0` 容器（转写进度卡从列表尾部上移至钉底区顶部）
2. `srcEntries.map` 平铺 → 按 `e.type` 分 `GROUPS`（pdf/pptx/url/code/dir 五组，色点 + 计数徽标 + 折叠）
3. 新增过滤 chips 与「收起卡片」开关；新增两个 localStorage 持久化 key
4. 卡片 DOM 结构不变（两行），仅第二行包一层 `grid-rows` 折叠壳
5. 形状异常提示条（srcAnom，L2118）保持在素材列表顶部，不参与分组
6. 不动：ResizablePanel、SOURCE/＋素材入口、条目5.3 SOURCE.md 变更即时回读、移除登记 Confirm、AI 注入口径
