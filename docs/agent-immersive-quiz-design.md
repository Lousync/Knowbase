# 沉浸教学自动出题设计（提取 / 生成 → 练习 → 沉淀）

> 状态：方案讨论稿（2026-09-03，先文档不写码）。归属：沉浸式 Agent 工作台（`agent-immersive-mode-design.md`）
> 教学场景深化；复用其 M1 产物机制与「跟我学」模板。配套现有资产：MarkdownPreview 的 quiz/大题渲染、
> 知识包答案排版规范（.AGENT/docs/knowledge-pack-answer-format.md）、quiz 系（错题本/quizbook）。

## 1. 目标

在沉浸「跟我学」教学闭环里加一道"练"：AI 讲完一个知识点/章节后，**自动出题**让用户当场练、
当场讲解；并可把题目**沉淀成可复习的题库文件**。两道题源：
- **自动生成**：根据刚讲的内容出题（选择/填空/简答/大题，答案+解析齐全）
- **自动提取**：用户资料里本来就有习题（PDF/PPT 含题）→ AI 通读后结构化抽取成题（消除手抄）

## 2. 现状盘点（能直接用的）

| 资产 | 形态 | 用途 |
|---|---|---|
| MarkdownPreview 渲染 | 对话内与知识页均渲染 ```quiz 选择题卡 与 大题 spoiler 解析 | **对话中出题=零后端**：AI 按格式输出即能作答 |
| 答案排版规范 | .AGENT/docs/knowledge-pack-answer-format.md（大题 (1)(2)(3)+解析 spoiler 规则） | 生成题目的排版基准，保证渲染与知识包兼容 |
| vault.write / 产物写入链路 | 已通（B2/沉浸 M1 计划） | 题目落成仓库内文件 |
| quiz 数据体系 | sqlite（错题本记录）+ quizbook 插件（C 级自有表）+ 知识包 quiz md | 错题/测验记录在 sqlite（去库化拍板保留），暂不开 AI 直写通道 |

关键结论：**对话内出题**无需任何后端改动（渲染现成）；**沉淀题库**最佳载体是仓库内 .md
题目文件（AI 原生可写、编辑器可改、阅读器可做题、可作知识包资产），不依赖 sqlite quiz 表。

## 3. 用户故事

- U1：讲完"分页表"→ AI 说"来 3 道题检验"并直接出 3 道选择题 → 我答 → 逐题批改讲解错因。
- U2：一节课结束，AI 提议"我把这章题目存成《测验·内存管理.md》，答案折叠起来"→ 我确认 →
  文件写入知识库；以后打开该页可整卷重做，图谱上与课程资料相连。
- U3：我给的讲义 PDF 第 4-7 页有 12 道练习题 → AI 通读后提取成题（题干/选项/答案）让我直接刷，
  不用边翻 PDF 边对答案。
- U4（远期）：做错的题自动记入错题本（quiz sqlite/quizbook），形成"讲→练→错题回顾"。

## 4. 设计（分层落地，零后端起步）

### L0 · 对话内出题（推荐先做，改提示词即可）
- 教学模板「跟我学」开场/出题规则里写明：测验题使用 ```quiz 选择题围栏 或 大题 spoiler
  （对齐排版规范），答案带解析并默认折叠展示。
- 触达：讲解中 agent 自主判断"该检验了"就出 3-5 题（≤8 轮内完成），批改讲解。
- 价值：即刻可用、所见即所得；实现=模板文案 + 简单 smoke 断言。

### L1 · 沉淀题库文件（随 M1 产物机制一起做）
- 约定：产物型题目页 = 仓库内普通 .md（如 `测验/内存管理.md`），frontmatter
  `{ type: quiz, tags: [课程/章节], source: 资料/日期 }`；正文 = 题组（大题 spoiler 或 ```quiz）。
- 流程：AI 产出草稿 → 沉浸右栏「产物」卡片（含题目预览+题目计数+双链来源）→ 用户点「写入」
  → vault.write 落库 → 该页成为可做题的知识页（阅读器渲染 quiz 卡），图谱出链。
- 文件组织：默认落到「测验」类目/目录（可配）；一题一文 vs 一课一卷？——默认**一课一卷**
  （文件粒度=课时，够复习粒度且文件不碎）。
- 复习入口：知识库内通过标签/搜索找到题卷打开即可重做（v1 不做专门"题库浏览页"，挂远期）。

### L2 · 错题联动（远期拍板）
- 题目做错 → 记录：需 quiz sqlite 写通道或 quizbook 插件接口；且 quiz 模块暂保留 sqlite
  （用户 09-02 拍板），AI 写错题需新工具+去库化联动；先不做，记录开放项。

## 5. 出题质量约束（写进规则，防废题）

1. 只围绕**刚讲过的内容**出题，明确对应到资料段落/本地笔记（每题标注出处）
2. 默认 3-5 题/次；题型轮换（选择→简答→大题）；答案必须含解析
3. 大题小问编号用规范 (1)(2)(3)；解析首行 `**解析**：`；代码块归属对应小问
4. 难度：先易后难 1 道基础+1-2 道变式+1 道综合；题干严谨避免"明显错误选项"
5. 生成题与资料已有题（U3 提取场景）去重提示

## 6. 集成点与分期

- **阶段 A（零后端，可立即做）**：教学模板 opening/出题规则补 L0 文案 → 真机即可体验对话出题
- **阶段 B（随 M1）**：L1 题卷产物（复用产物草稿+写入）；`type:quiz` frontmatter 与
  knowledgeIndex 标签支持核对（如标签未支持则退化为 tags 普通）
- **远期**：U4 错题本；独立"题库/复习"浏览视图；quizbook 插件可选联动（插件侧做题库页）

## 8. teach-skill 现状核查（2026-09-03 已读包）

来源：市场 `knowbase.teach-skill` v1.0.0（S 级，`contributes.skills: [{id: teach}]`，zip 内即 plugin.json、prompt 内嵌，源自 pjt222/agent-almanac，MIT，已中文化）。解包实测仅 1 个 plugin.json（~2.4KB）。

其流程（六步）：① 评估学习者（新手/进阶/高阶/误解四档讲法）② 从已知到未知搭桥（一次一个新概念）③ 讲解校准深度（一句话开场→阶梯→最小示例→观察困惑）④ 检查理解（应用型提问/复述/变式，非背诵）⑤ 按反馈调整（装懂/糊涂/反驳/沉默分诊）⑥ 练习强化（应用练习→连下一步→参考→总结）。铁律：逐条小步、一次一问、检查≠考试。variables：`concept`/`learnerContext`；tools：web.search。

**缺口对照**（核查结论）：
- ✅ 覆盖：教学编排主骨架、口语化检查与开放练习、水平适配——沉浸「跟我学」应**优先挂接此 skill**，不自造教学规则
- ❌ 未覆盖：结构化题目（选择/填空/大题、```quiz 围栏、spoiler 答案规范）、自动出卷与批改讲解流程、资料内习题提取（U3）、题卷沉淀（L1）、难度/去重规则——即本设计核心

**衔接候选（待拍板）**：
- **A（推荐）**：新增独立「出题官」Skill（`quiz-generator`，variables：topic/资料/题型/题量/是否沉淀；tools：vault.read/docs.read-text/vault.write 等），与 teach **组合**：沉浸会话由 teach 负责讲与即时口头检查；进入测验（teach 第 4/6 步或用户点名）→ agent 调 quiz-generator 出结构化题并沉淀卷。职责单一、可独立进市场、不污染 teach
- B：出题段落追加进 teach prompt（改市场包或复制为自有资产，与市场更新冲突，不推荐）
- C：仅改沉浸「跟我学」模板 opening（零资产改动、最小可用，但只在沉浸 Tab 内）

> 落实施前：应用内装 teach-skill → 确认沉浸教学模板注入可用（已配置 skill 由 AgentRunner 清单自动可见）→ 按 A 做 quiz-generator（可随 M1 产物机制一起做）。
