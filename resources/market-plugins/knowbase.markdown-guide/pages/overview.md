# Markdown 基本语法概览

Markdown 是一种**轻量级标记语言**，排版语法简洁，让人们更多地关注内容本身而非排版。它使用易读易写的纯文本格式编写文档，可与 HTML 混编，可导出 HTML、PDF 以及本身的 `.md` 格式文件。因简洁、高效、易读、易写，Markdown 被大量使用，如 GitHub、Wikipedia、简书等。

## 核心思想

- **常用标记符号不超过十个**，日常写作记录绰绰有余，不到半小时即可掌握
- 让人**优雅地沉浸式记录，专注内容而不是纠结排版**

## 基本语法全览

| 语法 | 写法 | 效果 |
| --- | --- | --- |
| 标题 | `# 一级标题` | 1-6 级标题 |
| 段落 | 空行分隔文本 | 独立段落 |
| 换行 | 行尾两个空格或 `<br>` | 软换行 |
| 强调 | `**粗体**` / `*斜体*` | 粗体 / 斜体 |
| 引用块 | `> 内容` | 引用样式 |
| 列表 | `1.` / `-` | 有序 / 无序列表 |
| 代码 | `` `行内` `` / 缩进块 | 代码样式 |
| 分隔线 | `---` | 水平分割线 |
| 链接 | `[文字](地址)` | 可点击链接 |
| 图片 | `![alt](地址)` | 图片 |
| 转义 | `\*` | 显示字面字符 |
| HTML | `<span>` 等标签 | 精细排版控制 |
