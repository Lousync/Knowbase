# 代码语法

要将单词或短语表示为代码，请将其包裹在**反引号**（`` ` ``）中。

## 行内代码

```markdown
At the command prompt, type `nano`.
```

## 转义反引号

如果代码内容本身包含反引号，可以用**双反引号**包裹：

```markdown
Use ``code` in your Markdown file.
```

（即用 `` `` `` 包裹 `` `code` ``）

## 代码块

将代码块的每一行**缩进至少四个空格或一个制表符**：

```markdown
    <html>
      <head>
      </head>
    </html>
```

> 提示：要创建不需要缩进的代码块，请使用**围栏式代码块**（fenced code blocks，属扩展语法）：用三个反引号包裹，并可标注语言实现语法高亮：

```markdown
​```python
print("hello")
​```
```

## 适用场景速查

| 场景 | 写法 |
| --- | --- |
| 行内提及变量/命令 | 单反引号 |
| 内容含反引号 | 双反引号包裹 |
| 多行代码 | 缩进 4 空格（基本语法） |
| 多行代码 + 语法高亮 | 围栏式代码块（扩展语法） |
