# 段落语法

要创建段落，请使用**空白行**将一行或多行文本进行分隔。

## 基本用法

```markdown
I really like using Markdown.

I think I'll use it to format all of my documents from now on.
```

渲染效果：

I really like using Markdown.

I think I'll use it to format all of my documents from now on.

## 最佳实践

**不要用空格或制表符缩进段落。**

| ✅ 正确 | ❌ 错误 |
| --- | --- |
| 段落保持左对齐，前后用空行分隔 | 段落前添加空格或 Tab，可能导致意外格式问题 |

> 注意：单独的换行不会产生新段落——段落之间必须用空行隔开（换行的处理见「换行语法」）。
