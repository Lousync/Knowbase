# 列表语法(有序/无序/嵌套)

可以将多个条目组织成**有序**或**无序**列表。

## 有序列表

每个列表项前添加**数字 + 英文句点**。数字不必按数学顺序排列，但列表应以 `1` 起始：

```markdown
1. First item
2. Second item
3. Third item
```

> 兼容性提示：请只使用句点（`.`）作分隔符；`1) First item` 的右括号写法并非所有应用都支持。

## 无序列表

每个列表项前添加破折号（`-`）、星号（`*`）或加号（`+`）：

```markdown
- First item
- Second item
- Third item
```

> 兼容性提示：**不要在同一个列表中混合使用多种分隔符**——选择一种并始终保持一致。

## 嵌套列表

缩进一个或多个列表项即可创建嵌套列表：

```markdown
1. First item
2. Second item
3. Third item
    - Indented item
    - Indented item
4. Fourth item
```

## 在列表中嵌套其他元素

要在保留列表连续性的同时加入其它元素，将该元素**缩进四个空格或一个制表符**：

- **段落**：缩进 4 空格
- **引用块**：缩进 4 空格，如 `    > A blockquote`
- **代码块**：缩进 **八个空格或两个制表符**（在列表内）
- **图片**：缩进 4 空格
- **列表**：有序嵌套无序（反之亦然），缩进即可
