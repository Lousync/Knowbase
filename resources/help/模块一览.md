# 模块一览

**一句话**：活动栏上每个图标是一个模块，下面是它们各自负责什么。

## 写作与记录

| 模块 | 负责 | 典型场景 |
|---|---|---|
| **博客 · 日志** | 按天的写作与回顾 | 写日记、周报、月总结 |
| **编辑区** | 文件与目录的**唯一写入方** | 新建 / 编辑 / 重命名 / 移动 `.md` 文件 |
| **知识库** | 阅读与组织已有页面 | 双链、标签、知识网络、全文搜索 |
| **说说** | 轻量动态与相册 | 随手记一句、存图 |

## 任务与习惯

| 模块 | 负责 | 典型场景 |
|---|---|---|
| **任务** | 日程安排与四象限管理 | 待办、周视图、每日打卡 |

## AI

| 模块 | 负责 | 典型场景 |
|---|---|---|
| **AI 助手**（侧栏 / AI 学堂） | 通用助手：读文件、写文件、整理、答疑 | `Ctrl J` 唤起；选中文字问 AI；**AI 学堂**里跟着上手路径学用软件 |
| **AI 教学** | 面向**学一门课**的工作台 | 上传资料、生成讲义、出题、产物归档 |

> 两者用的是同一套模型与会话库，但**会话列表互相隔离**：通用助手的任务（文件操作、答疑）不会混进教学工作区，反之亦然。

## 工具与扩展

| 模块 | 负责 |
|---|---|
| **工具箱** | 番茄钟、习惯打卡、密码本、体重追踪、网址导航、导出备份、局域网互传等 |
| **插件** | 主题 / 预设 / 知识包市场（S/A/B 三级安全审核） |
| **回收站** | 找回被删除的内容 |

## 系统

| 模块 | 负责 |
|---|---|
| **设置** | 外观、编辑器、模块开关、AI 工具与权限、数据与导出 |
| **帮助** | 你正在看的这套手册 |
| **个人** | 昵称、头像、使用统计 |
