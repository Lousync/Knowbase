把打卡实时推送给监督者(如家长、朋友)的微信 / 钉钉 / 企业微信群,支持每日汇总与失败补推。

## 支持的推送渠道

| 渠道 | 需要配置 | 获取方式 |
|------|----------|----------|
| Server酱 | SendKey | 监督者微信扫码登录 [sct.ftqq.com](https://sct.ftqq.com) 复制 SendKey,关注「方糖」服务号接收;免费版每天限 5 条 |
| 企业微信机器人 | Webhook 地址 | 群设置 → 群机器人 → 添加,无条数限制 |
| 钉钉机器人 | Webhook 地址 + 加签密钥(SEC 开头) | 群设置 → 智能群助手 → 添加机器人,安全设置选「**加签**」 |
| 自定义 Webhook | 任意 URL | 向该地址 POST JSON(`{ title, content, timestamp }`),HTTP 200 视为成功 |

## 配置步骤

1. 打开 **工具箱 → 远程监督**,开启「启用远程监督」总开关
2. 选择平台,粘贴地址 / SendKey(钉钉还需填写加签密钥)
3. 点击「保存配置」,再点「**发送测试消息**」验证(会自动先保存)

## 推送时机

- **打卡即时推送**(默认开):每次习惯打卡成功,立即推送「✅ 打卡「习惯名」」,附连续天数
- **每日汇总**(默认关,可设发送时间,默认 22:00):汇总当天全部习惯完成情况「📋 每日汇总:X/Y 完成」,逐条列出 ✅ / ⬜
- **免打扰时段**:可设起止时间(支持跨天,如 23:00~07:00);时段内推送先挂起,结束后自动补发

## 重试与推送历史

- 发送失败自动重试,单条最多 4 次(间隔 1 / 5 / 15 秒)
- 「推送历史」标签页可查看最近推送记录(成功 / 失败 / 挂起、失败原因、尝试次数):
  - 单条失败可点「重推」
  - 右上「补推全部失败」一键批量补推
  - 「清空历史」为两步确认,防止误触

> Webhook 地址与密钥**仅保存在本机**,请勿分享给他人。每日汇总每天自动尝试一次,失败请到历史页手动补推。
