# 唯物辩证法：三大规律与五对范畴

> 唯物辩证法是马原选择题与分析题的"主战场"，务必把三大规律的**方法论意义**背熟。

## 一、两大总特征

| 总特征 | 核心要点 |
|---|---|
| 联系 | 联系具有客观性、普遍性、多样性、条件性；整体与部分、系统观 |
| 发展 | 发展的实质是**新事物的产生和旧事物的灭亡**；前进性与曲折性 |

## 二、三大规律

### 1. 对立统一规律（矛盾规律）—— 唯物辩证法的**实质和核心**

| 内容 | 要点 |
|---|---|
| 矛盾的同一性与斗争性 | 同一性（相互依存、相互贯通转化）与斗争性（相互排斥）**相结合**推动事物发展；斗争性寓于同一性之中 |
| 矛盾的普遍性与特殊性 | 普遍性寓于特殊性之中；**共性与个性的关系是矛盾问题的精髓**；具体问题具体分析 |
| 主要矛盾与次要矛盾 | 抓主要矛盾、统筹兼顾 |
| 矛盾的主要方面与次要方面 | 抓主流，分清主流支流 |
| 方法论 | 具体问题具体分析；两点论与重点论相统一 |

### 2. 量变质变规律

| 概念 | 要点 |
|---|---|
| 质、量、度 | **度**是保持事物质稳定性的数量界限；适度原则 |
| 量变与质变 | 量变是质变的必要准备，质变是量变的必然结果；量变和质变相互渗透 |
| 方法论 | 注重量的积累，为质变创造条件；把握适度原则 |

### 3. 否定之否定规律

| 概念 | 要点 |
|---|---|
| 辩证否定观 | 否定是事物的**自我否定**；辩证否定的实质是"**扬弃**"（既克服又保留） |
| 否定之否定 | 事物发展是**螺旋式上升、波浪式前进**；前进性与曲折性的统一 |
| 方法论 | 对一切事物采取科学分析态度，反对肯定一切或否定一切 |

## 三、五对基本范畴（联系和发展的基本环节）

| 范畴 | 关系要点 |
|---|---|
| 内容与形式 | 内容决定形式，形式反作用于内容 |
| 本质与现象 | 现象是外部表现（可为假象），本质是内在联系；**透过现象认识本质** |
| 原因与结果 | 因果联系是客观普遍的联系 |
| 必然与偶然 | 必然居于支配地位、决定事物发展方向；偶然是必然的补充；**通过偶然认识必然** |
| 现实与可能 | 可能与现实的辩证转化；发挥主观能动性创造条件 |

## 四、易错提示

- 矛盾的**普遍性（共性）寓于特殊性（个性）之中**，方向不能反。
- 辩证否定的实质是"**扬弃**"，即"既克服又保留"，不是全盘否定。
- "度"是**限度**（质与量的统一），超出度就发生质变——考"适度原则"。
- 对立统一规律是辩证法的**实质和核心**（因为它揭示了事物发展的**动力和源泉**）。
