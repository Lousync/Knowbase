# 毛泽东重要著作速查表

> 著作题常考"**首次提出什么**"与"**哪篇著作对应哪个思想**"。按时间顺序记忆即可。

## 一、大革命与土地革命时期

| 著作 | 年份 | 核心内容 / 首次提出 |
|---|---|---|
| 《中国社会各阶级的分析》 | 1925 | 新民主主义革命基本思想；**分清敌友是革命首要问题** |
| 《湖南农民运动考察报告》 | 1927 | 充分肯定农民革命；农民问题是国民革命中心问题 |
| 《中国的红色政权为什么能够存在？》《井冈山的斗争》 | 1928 | 工农武装割据思想 |
| 《关于纠正党内的错误思想》 | 1929 | 思想建党、政治建军原则 |
| 《星星之火，可以燎原》 | 1930 | **农村包围城市、武装夺取政权**道路 |
| 《反对本本主义》 | 1930 | 反对教条主义；"没有调查，没有发言权"；**思想路线**的初步提出 |

## 二、抗日战争时期

| 著作 | 年份 | 核心内容 / 首次提出 |
|---|---|---|
| 《论反对日本帝国主义的策略》 | 1935 | 抗日民族统一战线的策略 |
| 《实践论》《矛盾论》 | 1937 | 马克思主义中国化的哲学基础 |
| 《论持久战》 | 1938 | 持久战三阶段（战略防御→相持→反攻） |
| 《中国共产党在民族战争中的地位》 | 1938 | 提出"马克思主义中国化" |
| 《〈共产党人〉发刊词》 | 1939 | **三大法宝**：统一战线、武装斗争、党的建设 |
| 《中国革命和中国共产党》 | 1939 | 第一次提出"**新民主主义革命**"科学概念 |
| 《新民主主义论》 | 1940 | 新民主主义革命理论**完整形成**；"两步走" |
| 《改造我们的学习》 | 1941 | **实事求是**思想路线的完整阐述；整风运动 |
| 《论联合政府》（七大报告） | 1945 | **三大作风**：理论联系实际、密切联系群众、批评与自我批评 |

## 三、解放战争时期与建国后

| 著作 | 年份 | 核心内容 / 首次提出 |
|---|---|---|
| 《在晋绥干部会议上的讲话》 | 1948 | 完整表述**新民主主义革命总路线**（无产阶级领导的、人民大众的、反对帝国主义封建主义官僚资本主义的革命） |
| 《将革命进行到底》 | 1948 | 第一次公开使用"**人民民主专政**" |
| 《论人民民主专政》 | 1949 | 人民民主专政理论；工人阶级领导、工农联盟为基础 |
| 《论十大关系》 | 1956 | 探索中国自己的社会主义建设道路；调动一切积极因素 |
| 《关于正确处理人民内部矛盾的问题》 | 1957 | 社会主义社会基本矛盾；正确处理人民内部矛盾是国家政治生活主题 |

## 四、易混辨析

- **"三大法宝"**在《〈共产党人〉发刊词》（1939）；**"三大作风"**在《论联合政府》（1945），勿混淆。
- **首次提出"马克思主义中国化"**：六届六中全会（1938）《论新阶段》，不是《中国共产党在民族战争中的地位》。
- **新民主主义革命总路线**：完整表述在《在晋绥干部会议上的讲话》（1948），此前多部著作只涉及部分内容。
- **毛泽东思想活的灵魂**：实事求是（根本思想路线）、群众路线（根本工作路线）、独立自主（根本政治原则）。
