# 政治经济学核心：商品、剩余价值与资本

> 马原政治经济学（政经）占比逐年上升，核心是**劳动价值论**与**剩余价值论**两大块。注意计算题与概念辨析。

## 一、劳动价值论（商品的二因素与劳动的二重性）

| 概念 | 要点 |
|---|---|
| 商品二因素 | **使用价值**（自然属性，具体劳动创造）与**价值**（社会属性，抽象劳动凝结） |
| 劳动二重性 | **具体劳动**创造使用价值，**抽象劳动**形成价值；劳动二重性学说是理解政治经济学的枢纽 |
| 价值量 | 由生产商品的**社会必要劳动时间**决定；与劳动生产率成**反比** |
| 货币 | 本质是固定充当**一般等价物**的商品；五种职能：价值尺度、流通手段、贮藏手段、支付手段、世界货币 |
| 价值规律 | 商品价值量由社会必要劳动时间决定，商品交换以价值量为基础等价交换；表现形式：价格围绕价值上下波动 |
| 商品经济基本矛盾 | **私人劳动与社会劳动的矛盾** |

## 二、剩余价值论

| 概念 | 要点 |
|---|---|
| 劳动力成为商品 | 货币转化为资本的前提条件；劳动力商品的价值＝生活资料价值，使用价值＝创造新价值 |
| 剩余价值（m） | 雇佣工人**剩余劳动**创造的、被资本家无偿占有的超过劳动力价值的价值 |
| 不变资本（c）与可变资本（v） | c＝生产资料（不增值），v＝劳动力（增值）；**划分依据：在剩余价值生产中的不同作用** |
| 剩余价值率 m' | m'＝m/v＝剩余劳动时间/必要劳动时间 |
| 绝对剩余价值 | 延长工作日或提高劳动强度 |
| 相对剩余价值 | 缩短必要劳动时间（通过提高劳动生产率） |
| 超额剩余价值 | 个别企业率先提高劳动生产率获得（**相对剩余价值是超额剩余价值的普遍化**） |
| 资本积累 | 剩余价值资本化；源泉是剩余价值；后果是两极分化、失业 |

### 资本有机构成（重要，2026 分析题考点）

- **技术构成**：由技术水平决定的生产资料与劳动力的比例（物质形态）。
- **价值构成**：不变资本与可变资本的比例（c:v）（价值形态）。
- **有机构成**：由技术构成决定、并反映技术构成变化的资本价值构成（**c:v**）。
- 趋势：资本有机构成不断提高 → 相对过剩人口 → 平均利润率下降。

## 三、资本循环周转与再生产

| 概念 | 要点 |
|---|---|
| 资本循环三阶段 | 购买阶段 → 生产阶段 → 售卖阶段；三种职能形式：货币资本、生产资本、商品资本 |
| 资本周转 | 周转时间（生产时间＋流通时间）；加快周转提高年剩余价值率 |
| 固定资本与流动资本 | 按**价值周转方式**划分 |
| 社会再生产 | 简单再生产与扩大再生产；两大部类（生产资料、消费资料）平衡 |

## 四、资本主义基本矛盾与经济危机

- **基本矛盾**：生产社会化与生产资料资本主义私人占有之间的矛盾。
- **经济危机**：本质特征是**生产相对过剩**；根源是资本主义基本矛盾；具有周期性（危机→萧条→复苏→高涨）。

## 五、易错提示

- **不变资本/可变资本**按"在剩余价值生产中的作用"划分；**固定资本/流动资本**按"价值周转方式"划分——两对概念勿混淆。
- 剩余价值的**唯一源泉是雇佣工人的剩余劳动**，不是科技、机器。
- 劳动生产率提高 → 单位商品价值量**下降**（社会必要劳动时间减少），价值总量不变。
- 资本主义工资的本质是**劳动力的价值或价格**，不是劳动的价格。
