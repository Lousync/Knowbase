# 党史重要会议速查表（一大—二十大）

> 会议题是史纲与毛中特的高频考点，抓住每次会议的**"唯一标签"**即可秒排干扰项。

## 一、新民主主义革命时期

| 会议 | 时间 | 核心内容（"功能标签"） |
|---|---|---|
| 中共一大 | 1921 | **建党**（开天辟地）；中心工作＝组织领导工人运动 |
| 中共二大 | 1922 | **立纲**：第一次提出反帝反封建的民主革命纲领；开始采取群众路线 |
| 中共三大 | 1923 | **国共合作**：决定共产党员以个人身份加入国民党 |
| 国民党一大 | 1924 | 国共第一次合作正式形成；新三民主义 |
| 中共四大 | 1925 | 第一次提出**无产阶级领导权**与工农联盟 |
| 八七会议 | 1927 | **枪杆子出政权**；纠正右倾；土地革命与武装反抗总方针 |
| 古田会议 | 1929 | 思想建党、政治建军；《关于纠正党内的错误思想》 |
| 遵义会议 | 1935 | **生死攸关转折点**；解决军事与组织问题；独立自主 |
| 瓦窑堡会议 | 1935 | 抗日民族统一战线策略方针 |
| 洛川会议 | 1937 | 全面抗战路线（人民战争路线）；敌后游击战 |
| 中共六届六中全会 | 1938 | 第一次提出"**马克思主义中国化**"命题 |
| 中共七大 | 1945 | **毛泽东思想写入党章**；《论联合政府》；三大作风 |
| 中共七届二中全会 | 1949 | 工作重心**乡村→城市**；"两个务必"；从农业国转向工业国 |
| 新政协（一届） | 1949 | 《共同纲领》临时宪法作用；新中国成立 |

## 二、社会主义革命与建设时期

| 会议 | 时间 | 核心内容 |
|---|---|---|
| 中共七届三中全会 | 1950 | 争取国家财政经济状况基本好转 |
| 一届全国人大 | 1954 | 第一部社会主义类型宪法；人民代表大会制度 |
| 中共八大 | 1956 | 正确分析主要矛盾（先进社会制度 vs 落后生产力）；既反保守又反冒进 |
| 中共八大二次会议 | 1958 | 提出"鼓足干劲、力争上游、多快好省"总路线 |
| 三届全国人大 | 1964 | 提出"四个现代化" |

| 会议 | 时间 | 核心内容 |
|---|---|---|
| 十一届三中全会 | 1978 | **伟大转折**；否定"两个凡是"；以经济建设为中心；改革开放 |

| 中共十二大 | 1982 | 提出"建设有中国特色的社会主义" |

| 中共十三大 | 1987 | 社会主义初级阶段理论；"一个中心、两个基本点"基本路线；三步走 |
| 中共十四大 | 1992 | 建立社会主义市场经济体制；确立邓小平理论指导地位 |
| 中共十五大 | 1997 | 邓小平理论写入党章；确立基本经济制度；依法治国 |
| 中共十六大 | 2002 | "三个代表"写入党章；全面建设小康社会 |
| 中共十七大 | 2007 | 科学发展观写入党章；中国特色社会主义理论体系 |
| 中共十八大 | 2012 | 科学发展观写入党章；确立"五位一体"总布局 |
| 十八届三中全会 | 2013 | 全面深化改革总目标：完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化 |
| 十八届四中全会 | 2014 | 全面依法治国 |
| 十八届五中全会 | 2015 | 新发展理念（创新协调绿色开放共享） |
| 中共十九大 | 2017 | 习近平新时代中国特色社会主义思想写入党章；我国社会主要矛盾变化 |
| 十九届四中全会 | 2019 | 坚持和完善中国特色社会主义制度、推进国家治理现代化 |
| 十九届五中全会 | 2020 | "十四五"规划；全面建设社会主义现代化国家 |
| 十九届六中全会 | 2021 | 第三个历史决议；"两个确立" |
| 中共二十大 | 2022 | 中国式现代化；两步走战略安排 |

## 四、易混辨析

- **第一次提出"马克思主义中国化"**：六届六中全会（1938），非七大。
- **确立毛泽东思想指导地位**：七大（1945）；**提出"毛泽东思想"概念**：王稼祥《中国共产党与中国民族解放的道路》（1943）。
- **"两个务必"**：七届二中全会（1949），西柏坡。
- **改革开放起点**：十一届三中全会（1978）；**"建设有中国特色社会主义"首次提出**：十二大（1982）。
- **主要矛盾变化**：八大（1956）一次、十九大（2017）一次，容易混考。
