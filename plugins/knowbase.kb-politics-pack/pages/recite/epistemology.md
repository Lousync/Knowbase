# 认识论核心：实践、认识、真理与价值

> 认识论是马原分析题最高频的"原理来源"之一，答题常套"实践决定认识 + 认识的辩证运动"。

## 一、实践（认识的基础）

| 要点 | 内容 |
|---|---|
| 实践的地位 | **实践的观点是马克思主义认识论首要的、基本的观点** |
| 实践的基本特征 | 直接现实性（本质特征）、自觉能动性、社会历史性 |
| 实践的基本结构 | 实践**主体**、实践**客体**、实践**中介**（工具手段） |
| 实践的基本形式 | **物质生产实践**（最基本）、社会政治实践、科学文化实践 |
| 实践对认识的决定作用 | 实践是认识的**来源、动力、目的、检验真理的唯一标准** |

## 二、认识的本质与运动规律

- **认识的本质**：主体对客体的**能动反映**（辩证唯物主义反映论，区别于旧唯物主义的直观反映与唯心主义的先验论）。
- **两次飞跃**：

```
感性认识（感觉/知觉/表象） ——第一次飞跃——→ 理性认识（概念/判断/推理）
        （第二次飞跃：理性认识回到实践，意义更重大）
```

- **认识运动的规律**：实践 → 认识 → 再实践 → 再认识，循环往复、螺旋上升。
- **认识论的两个突出特点**：把实践观点引入认识论；把辩证法应用于反映论。

## 三、真理与谬误

| 概念 | 要点 |
|---|---|
| 真理的客观性 | 真理是客观的，内容客观、检验标准客观 |
| 真理的绝对性与相对性 | 任何真理都是绝对真理与相对真理的**统一**；两者相互包含、辩证转化 |
| 真理与谬误 | 相伴而生，在一定条件下**相互转化** |
| 检验标准 | **实践是检验真理的唯一标准**；实践标准具有**确定性与不确定性**（相对性） |

## 四、真理与价值

| 概念 | 要点 |
|---|---|
| 价值及其特性 | 客体对主体的意义；特性：客观性、主体性、社会历史性、多维性 |
| 价值评价 | 以主体的需要为尺度，正确评价需符合社会历史发展客观规律 |
| 真理尺度与价值尺度 | 真理尺度（规律）与价值尺度（需要）的统一；**坚持真理与价值相统一** |
| 价值观 | 社会主义核心价值观的引领作用 |

## 五、主观能动性与客观规律性

- 尊重客观规律是正确发挥主观能动性的**前提**。
- 发挥主观能动性是认识和利用客观规律的**必要条件**。
- 方法论：一切从实际出发、实事求是；坚持**守正创新**，理论创新与实践创新良性互动。

## 六、易错提示

- 感性认识上升到理性认识的条件：**占有丰富而真实的感性材料** + **运用科学思维方法加工制作**。
- 实践标准的不确定性不是"实践不能检验"，而是**具体历史条件下的实践有其局限性**。
- 真理的绝对性≠"永恒真理"，相对性≠"相对主义"——要反对绝对主义与相对主义两个极端。
- 认识论分析题万能切入点：**实践是认识的基础/来源/动力/标准**。
