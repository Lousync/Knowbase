# 中国近现代史大事记时间轴（1840—今）

> 史纲复习主线：**两大历史任务**（争取民族独立、人民解放 → 实现国家富强、人民富裕）与**四个历史时期**的划分。记住关键年份锚点，史纲的选择题基本不丢分。

## 一、历史分期总览

| 时期 | 时间 | 核心线索 |
|---|---|---|
| 旧民主主义革命时期 | 1840—1919 | 农民阶级、地主阶级、资产阶级的探索均告失败 |
| 新民主主义革命时期 | 1919—1949 | 无产阶级（共产党）领导，分大革命、土地革命、抗战、解放战争四阶段 |
| 社会主义革命与建设时期 | 1949—1978 | 社会主义改造 + 社会主义建设道路初步探索 |
| 改革开放和社会主义现代化建设新时期 | 1978—2012 | 中国特色社会主义开创与接续发展 |
| 中国特色社会主义新时代 | 2012—今 | 全面建成社会主义现代化强国 |

## 二、核心年份速查表

| 年份 | 事件 | 地位 / 考点 |
|---|---|---|
| 1840 | 鸦片战争 | **近代史开端**，社会性质变为半殖民地半封建社会 |
| 1842 | 《南京条约》 | 中国近代**第一个不平等条约** |
| 1894—1895 | 甲午中日战争、《马关条约》 | 民族危机空前加深，掀起义和团、戊戌维新 |
| 1898 | 戊戌维新运动 | 资产阶级改良，**民族资产阶级作为独立政治力量登上历史舞台**（开始） |
| 1900—1901 | 八国联军侵华、《辛丑条约》 | 清政府完全成为"洋人的朝廷"，半殖民地半封建社会**完全形成** |
| 1911 | 辛亥革命 | 结束封建君主专制制度，建立中华民国 |
| 1915 | 新文化运动（《青年杂志》） | 思想启蒙，为马克思主义传播创造条件 |
| 1919 | 五四运动 | **新民主主义革命的开端** |
| 1921 | 中共一大 | 中国共产党成立，**开天辟地的大事变** |
| 1927 | 南昌起义 / 八七会议 | **建军开端** / 确立土地革命与武装反抗总方针 |
| 1928 | 井冈山革命根据地 | 农村包围城市、武装夺取政权道路的开辟 |
| 1931 | 九一八事变 | 局部抗战开始 |
| 1935 | 遵义会议 | 生死攸关的转折点，独立自主解决中国革命问题 |
| 1935 | 瓦窑堡会议 | 制定抗日民族统一战线策略方针 |
| 1937 | 七七事变（卢沟桥事变） | **全面抗战开始** |
| 1945 | 中共七大 / 抗战胜利 | 毛泽东思想写入党章 / 第一次完全胜利的民族解放战争 |
| 1949 | 七届二中全会 / 新政协 / 新中国成立 | 工作重心由乡村转向城市 / 《共同纲领》临时宪法 / 新民主主义革命基本胜利 |
| 1953 | 过渡时期总路线 | "一化三改" |
| 1954 | 一届全国人大 | 第一部社会主义类型宪法 |
| 1956 | 中共八大 / 社会主义改造完成 | 社会主义基本制度确立，进入社会主义社会 |
| 1978 | 十一届三中全会 | **改革开放开端**，伟大转折 |
| 1982 | 中共十二大 | 提出"建设有中国特色的社会主义"命题 |
| 1987 | 中共十三大 | 系统阐述**社会主义初级阶段理论**与基本路线 |
| 1992 | 中共十四大 / 南方谈话 | 确立社会主义市场经济体制改革目标 |
| 1997 | 中共十五大 | 邓小平理论写入党章 |
| 2012 | 中共十八大 | 中国特色社会主义进入新时代 |
| 2017 | 中共十九大 | 习近平新时代中国特色社会主义思想写入党章 |
| 2022 | 中共二十大 | 系统阐述**中国式现代化** |

## 三、易混点提示

- **新旧民主主义革命的分界**：五四运动（1919）——根本区别是**领导阶级**（资产阶级 vs 无产阶级）。
- **近代史两大矛盾**：帝国主义和中华民族的矛盾（最主要）、封建主义和人民大众的矛盾。
- **三大起义**：南昌起义（1927-08-01，打响武装反抗第一枪）、秋收起义（1927-09，农村包围城市起点）、广州起义（1927-12）。
- **长征**：1934 年 10 月出发 → 1936 年 10 月三大主力会师。
