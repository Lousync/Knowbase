# 唯物辩证法：联系、发展与三大规律

> 辩证法马原分析题的"万金油"来源，几乎年年有题。重点掌握**对立统一规律**及其方法论。

## 一、两大总特征：联系与发展

### 联系
- 联系是事物内部各要素之间和事物之间**相互影响、相互制约、相互作用**的关系。
- **特点**：客观性、普遍性、多样性、条件性。
- 方法论：确立整体性、开放性观念，用联系的观点看问题。

### 发展
- 发展的**实质**：新事物的产生和旧事物的灭亡。
- 新事物必然战胜旧事物的原因：新事物符合历史前进方向、具有强大生命力、本质优越。
- 方法论：用发展的眼光看问题，把握前进性与曲折性的统一。

## 二、三大规律

### 1. 对立统一规律（矛盾规律）—— 唯物辩证法的实质和核心

| 内容 | 要点 |
|---|---|
| 矛盾的同一性与斗争性 | 同一性：相互依存、相互贯通；斗争性：相互排斥、相互对立。**斗争性寓于同一性之中**，两者结合推动事物发展 |
| 矛盾的普遍性与特殊性 | 普遍性寓于特殊性之中；**共性与个性的关系是矛盾问题的精髓** |
| 主要矛盾与次要矛盾 | 抓重点、抓主要矛盾；统筹兼顾 |
| 矛盾主要方面与次要方面 | 分清主流与支流 |
| 方法论 | **具体问题具体分析**（马克思主义活的灵魂）；两点论与重点论统一 |

### 2. 量变质变规律

- **质、量、度**：度是保持事物质的稳定性的**数量界限**（量变的范围和限度）。
- **量变与质变**：量变是质变的必要准备，质变是量变的必然结果；量变和质变相互渗透。
- 方法论：注重量的积累，为质变创造条件；坚持**适度原则**。

### 3. 否定之否定规律

- **辩证否定观**：否定是事物的自我否定；辩证否定的实质是"**扬弃**"（既克服又保留）。
- 事物发展是**螺旋式上升、波浪式前进**，前进性与曲折性的统一。
- 方法论：对事物采取科学分析态度，反对肯定一切或否定一切。

## 三、五对基本范畴（联系和发展的基本环节）

| 范畴 | 关系要点 | 方法论 |
|---|---|---|
| 内容与形式 | 内容决定形式，形式反作用于内容 | 反对形式主义 |
| 本质与现象 | 现象表现本质，本质决定现象；假象也是本质的表现 | 透过现象看本质 |
| 原因与结果 | 因果联系客观普遍 | 凡事预则立，不预则废 |
| 必然与偶然 | 必然决定方向，偶然起加速或延缓作用 | 把握必然，善于利用偶然 |
| 现实与可能 | 可能与现实的辩证转化 | 立足现实，创造条件 |

## 四、易错提示

- 对立统一规律之所以是**核心**，是因为它揭示了事物发展的**根本动力**（源泉）是矛盾。
- 矛盾的**普遍性（共性）寓于特殊性（个性）之中**，方向不能反。
- 辩证否定的实质是"**扬弃**"，不是全盘否定。
- "度"是**限度**（质与量的统一），超出度就发生质变。
