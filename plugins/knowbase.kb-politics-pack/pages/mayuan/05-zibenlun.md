# 资本主义本质：劳动价值论与剩余价值论

> 政治经济学（政经）在马原中占比上升，核心是**劳动价值论**与**剩余价值论**两大块，注意概念辨析与简单计算。

## 一、劳动价值论

### 商品的二因素与劳动的二重性

| 概念 | 内容 |
|---|---|
| 商品二因素 | **使用价值**（自然属性，具体劳动创造）与**价值**（社会属性，抽象劳动凝结） |
| 劳动二重性 | **具体劳动**创造使用价值，**抽象劳动**形成价值；劳动二重性学说是理解政治经济学的**枢纽** |
| 商品价值量 | 由生产商品的**社会必要劳动时间**决定；与劳动生产率成**反比** |

### 货币与价值规律

- **货币的本质**：固定充当**一般等价物**的商品。
- **货币的职能**：价值尺度、流通手段、贮藏手段、支付手段、世界货币（前两个为基本职能）。
- **价值规律**：商品价值量由社会必要劳动时间决定，商品交换以价值量为基础等价交换；表现形式是价格围绕价值**上下波动**。
- **商品经济的基本矛盾**：私人劳动与社会劳动的矛盾。

## 二、剩余价值论

### 核心概念

| 概念 | 要点 |
|---|---|
| 劳动力成为商品 | 货币转化为资本的**前提**；劳动力价值＝生活资料价值，使用价值＝创造新价值 |
| 剩余价值（m） | 雇佣工人**剩余劳动**创造的、被资本家无偿占有的超过劳动力价值的价值 |
| 不变资本 c / 可变资本 v | 按在剩余价值生产中的**不同作用**划分：c（生产资料，不增值）/ v（劳动力，增值） |
| 剩余价值率 m' | m' = m / v = 剩余劳动时间 / 必要劳动时间 |

### 剩余价值生产方法

| 方法 | 途径 |
|---|---|
| 绝对剩余价值 | 延长工作日、提高劳动强度 |
| 相对剩余价值 | 缩短必要劳动时间（提高全社会劳动生产率） |
| 超额剩余价值 | 个别企业率先提高劳动生产率；**相对剩余价值是超额剩余价值的普遍化** |

### 资本积累与有机构成（2026 分析题重点）

- **资本积累**：剩余价值的资本化；源泉是剩余价值；后果是两极分化、失业。
- **资本有机构成**（c:v）：由**技术构成**决定、并反映技术构成变化的**价值构成**。
  - 技术构成：生产资料与劳动力的比例（物质形态）
  - 价值构成：不变资本与可变资本的比例（价值形态）
- **趋势**：资本有机构成提高 → 相对过剩人口（失业）→ 平均利润率下降。

### 资本主义基本矛盾与经济危机

- **基本矛盾**：生产社会化与生产资料资本主义私人占有之间的矛盾。
- **经济危机**：本质特征是**生产相对过剩**；根源是资本主义基本矛盾；具有周期性（危机→萧条→复苏→高涨）。

## 三、易错提示

- **不变资本/可变资本**（按作用划分）≠ **固定资本/流动资本**（按价值周转方式划分）。
- 剩余价值的**唯一源泉**是雇佣工人的剩余劳动，不是科技、机器。
- 劳动生产率提高 → 单位商品价值量**下降**，价值总量不变。
- 资本主义工资的本质是**劳动力的价值或价格**，不是劳动的价格。
