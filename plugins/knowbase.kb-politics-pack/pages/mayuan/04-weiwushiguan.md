# 唯物史观：社会基本矛盾与人民群众

> 唯物史观是马克思的"第一个伟大发现"，重点是社会基本矛盾运动规律与人民群众的历史作用。

## 一、社会存在与社会意识

| 概念 | 内容 |
|---|---|
| 社会存在 | 社会生活的物质方面：自然地理环境、人口因素、物质生产方式 |
| 社会意识 | 社会生活的精神方面：社会心理、社会意识形式（含意识形态与非意识形态） |
| 核心关系 | **社会存在决定社会意识**，社会意识对社会存在有能动的反作用 |

- **物质生产方式**是社会历史发展的**决定力量**（决定社会性质、变革）。

## 二、社会基本矛盾及其运动规律

| 矛盾 | 关系 |
|---|---|
| 生产力与生产关系 | 生产力**决定**生产关系；生产关系**反作用**于生产力 |
| 经济基础与上层建筑 | 经济基础**决定**上层建筑；上层建筑**反作用**于经济基础 |

- **两大规律**：生产关系一定要适应生产力状况的规律；上层建筑一定要适应经济基础状况的规律。
- **生产力**：最革命、最活跃的因素；**科学技术是第一生产力**。
- **社会形态更替**：统一性与多样性的统一、必然性与选择性的统一。

## 三、社会历史发展的动力

| 动力 | 作用 |
|---|---|
| 社会基本矛盾 | **根本动力**（生产力与生产关系、经济基础与上层建筑的矛盾） |
| 阶级斗争 | 阶级社会发展的直接动力 |
| 社会革命 | 阶级斗争的最高形式，社会发展的重要动力 |
| 改革 | 社会主义社会发展的**直接动力**（社会主义社会基本矛盾的性质决定的） |
| 科学技术 | 对社会发展有重大作用，需正确把握其双重效应 |

## 四、人民群众在历史发展中的作用

| 要点 | 内容 |
|---|---|
| 人民群众 | 历史的**创造者**；是社会物质财富、精神财富的创造者，社会变革的决定力量 |
| 群众观点、群众路线 | 一切为了群众、一切依靠群众；从群众中来、到群众中去 |
| 杰出人物 | 起重要作用，但不能决定历史发展趋势；正确评价历史人物 |
| 群众、阶级、政党、领袖的关系 | 四者相互联系、相互依存 |

## 五、易错提示

- 社会历史发展的**根本动力**是社会基本矛盾（不是阶级斗争——那是阶级社会的直接动力）。
- **改革**是社会主义社会发展的直接动力（社会主义社会基本矛盾是非对抗性的，靠改革解决）。
- 人民群众是历史的创造者，但创造活动受社会历史条件**制约**。
- 历史唯物主义与历史唯心主义的根本分歧：社会存在与社会意识何者为第一性。
