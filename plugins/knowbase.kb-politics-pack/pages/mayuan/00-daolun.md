# 导论：马克思主义是关于无产阶级和人类解放的科学

> 本章是马原总纲，选择题常考"马克思主义的内涵、鲜明特征、历史地位"，难度低，务必拿稳。

## 一、什么是马克思主义

马克思主义是**由马克思和恩格斯创立、并为后继者所不断发展的科学理论体系**。

- **内容**：关于自然、社会和人类思维发展**一般规律**的学说。
- **目的**：关于社会主义**必然代替资本主义**、最终实现共产主义的学说。
- **立场**：关于无产阶级解放、全人类解放和每个人自由而全面发展的学说。
- **地位**：无产阶级政党和社会主义国家的指导思想，指引人民创造美好生活的行动指南。

## 二、马克思主义的创立与发展

| 要点 | 内容 |
|---|---|
| 社会根源 | 资本主义生产方式及其内在矛盾 |
| 阶级基础（实践基础） | 无产阶级反抗资产阶级压迫的斗争 |
| 思想渊源 | 德国古典哲学、英国古典政治经济学、英法两国空想社会主义 |
| 诞生标志 | 1848 年《共产党宣言》发表 |

- **发展**：列宁主义；马克思主义中国化时代化（毛泽东思想、中国特色社会主义理论体系、习近平新时代中国特色社会主义思想）。

## 三、马克思主义的基本特征（鲜明特征）

| 特征 | 含义 |
|---|---|
| **科学性** | 揭示自然界、人类社会、人类思维发展的一般规律 |
| **人民性** | 人民至上是马克思主义的**政治立场**；人民性是马克思主义**最鲜明的品格** |
| **实践性** | 从实践中来、到实践中去、在实践中检验和发展 |
| **发展性** | 是不断发展的开放的理论体系 |

## 四、马克思主义的当代价值

1. 观察当代世界变化的**认识工具**。
2. 指引当代中国发展的**行动指南**。
3. 引领人类社会进步的**科学真理**。

## 五、马克思主义哲学的两大基石

- **辩证唯物主义**与**历史唯物主义**（历史唯物主义是马克思**第一个伟大发现**，剩余价值学说是第二个）。

## 六、易错提示

- 马克思主义的**首要的和基本的观点**是实践的观点（贯穿认识论）。
- 人民性是马克思主义**最鲜明的品格**；不要与"科学性""实践性"混为一谈。
- 《共产党宣言》是诞生标志；《资本论》系统阐述剩余价值理论。
- 马克思主义中国化时代化的最新成果：习近平新时代中国特色社会主义思想。
