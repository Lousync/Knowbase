# 垄断资本主义、经济全球化与当代变化

> 本章聚焦资本主义由自由竞争向垄断阶段的发展，以及当代资本主义的新变化，选择题为主。

## 一、垄断资本主义的形成与发展

| 要点 | 内容 |
|---|---|
| 垄断形成 | 生产集中 → 垄断（自由竞争引起生产集中，生产集中发展到一定阶段必然产生垄断） |
| 垄断与竞争 | 垄断**没有消除竞争**，反而使竞争更加激烈、复杂 |
| 金融资本 | 工业垄断资本与银行垄断资本融合形成；金融寡头是操纵国民经济命脉的垄断资本集团 |
| 垄断利润、垄断价格 | 垄断组织凭借垄断地位获取的高额利润；垄断价格＝成本＋垄断利润 |

### 国家垄断资本主义

- **形成原因**：科技进步和生产社会化程度提高，资本主义基本矛盾进一步尖锐化的结果。
- **主要形式**：国有企业、国家与私人合营、国家调节经济。
- **实质**：垄断资本利用国家政权维护垄断统治、保证获得高额垄断利润，没有改变资本主义性质。

## 二、经济全球化

| 要点 | 内容 |
|---|---|
| 表现 | 生产全球化、贸易全球化、金融全球化 |
| 动因 | 科技革命和生产力发展（根本动因）、跨国公司发展、各国经济体制改革 |
| 影响 | 双刃剑：促进世界经济发展；加剧全球经济不平衡、风险 |

## 三、当代资本主义的新变化

| 变化 | 实质 |
|---|---|
| 生产资料所有制变化（资本社会化） | 没有改变资本主义私有制的基础 |
| 劳资关系和分配关系变化（福利国家） | 没有改变资本家剥削雇佣工人的本质 |
| 社会阶层、阶级结构变化 | 无产阶级仍是先进生产力代表 |
| 经济调节机制和经济危机形态变化 | 没有消除经济危机 |
| 政治制度变化 | 没有改变资产阶级民主的阶级本质 |

- **实质**：当代资本主义的新变化**没有改变资本主义制度的本质**，没有改变生产资料的私有制基础，没有改变基本矛盾。

## 四、资本主义的历史地位与发展趋势

- **历史地位**：资本主义是比封建制度进步的社会制度，但必然被社会主义所代替。
- **必然性**：资本主义基本矛盾决定了其被社会主义代替的**历史必然性**（"两个必然"——资本主义必然灭亡、社会主义必然胜利）。
- **长期性**：这一过程是长期的、曲折的（"两个绝不会"——在条件成熟前不会灭亡）。

## 五、易错提示

- 垄断**没有消除竞争**，竞争在垄断下更加激烈。
- 国家垄断资本主义**没有改变资本主义性质**。
- 经济全球化是**双刃剑**，本质是资本的全球扩张。
- "两个必然"与"两个绝不会"是统一的：趋势的必然性与过程的长期性。
