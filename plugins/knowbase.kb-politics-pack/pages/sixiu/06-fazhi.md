# 学习法治思想、提升法治素养（法治）

> 思修第六章（法治），全面依法治国、宪法、法治体系、权利义务是高频考点。

## 一、法律基础

| 要点 | 内容 |
|---|---|
| 法律的本质 | 统治阶级意志的体现，由国家制定或认可，以国家强制力保证实施 |
| 法律的特征 | 国家意志性、国家强制性、权利义务性、规范性 |
| 法律运行的环节 | 立法、执法、司法、守法（立法是前提，执法是关键） |
| 我国社会主义法律 | 体现了党的主张和人民意志的统一 |

## 二、全面依法治国

| 要点 | 内容 |
|---|---|
| 总目标 | 建设中国特色社会主义法治体系、建设社会主义法治国家 |
| 基本格局 | 科学立法、严格执法、公正司法、全民守法 |
| 道路 | 中国特色社会主义法治道路（坚持党的领导、人民主体地位、法律面前人人平等、依法治国与以德治国相结合、从中国实际出发） |
| 核心要义 | 坚持党的领导、坚持中国特色社会主义制度、贯彻中国特色社会主义法治理论 |

## 三、宪法（根本法）

| 要点 | 内容 |
|---|---|
| 地位 | 宪法是国家的**根本法**，具有最高法律效力 |
| 核心 | 宪法确立了党的领导地位、人民当家作主、依法治国有机统一 |
| 原则 | 人民主权、尊重和保障人权、法治、民主集中制 |

## 四、中国特色社会主义法治体系

| 内容 | 组成 |
|---|---|
| 法律规范体系 | 完备的法律规范体系（以宪法为核心、以法律为主干） |
| 法治实施体系 | 高效的法治实施体系 |
| 法治监督体系 | 严密的法治监督体系 |
| 法治保障体系 | 有力的法治保障体系 |

## 五、权利义务

- **公民基本权利**：政治权利和自由、人身权利、经济社会文化权利等。
- **公民基本义务**：维护国家统一和民族团结、遵守宪法法律、维护祖国安全荣誉利益、依法纳税等。
- **权利义务的关系**：权利与义务相统一，没有无义务的权利，也没有无权利的义务。

## 六、易错提示

- 宪法是国家的**根本法**（不是普通法律），具有最高法律效力。
- 全面依法治国总目标是建设中国特色社会主义**法治体系**、建设社会主义**法治国家**。
- 法律运行的**前提**是立法（有法可依），**关键**是执法。
- 依法治国与**以德治国**相结合，是中国特色社会主义法治道路的重要特色。
