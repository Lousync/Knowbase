# 遵守道德规范、锤炼道德品格（道德）

> 思修第五章，道德的本质、功能、核心原则是选择题高频，家风/诚信等是分析题素材。

## 一、道德的本质与功能

| 要点 | 内容 |
|---|---|
| 道德的起源 | 社会关系的产物，劳动是道德产生的根本动因 |
| 道德的本质 | 一种**上层建筑**，由经济基础决定，是调节利益关系的特殊行为规范 |
| 道德的功能 | 认识功能、规范功能、调节功能（调节是道德最主要的功能） |
| 道德的作用 | 调节社会关系、维护社会秩序、促进社会发展 |

## 二、中华传统美德与革命道德

- **中华传统美德**：仁爱、诚信、孝悌、勤俭、自强等；创造性转化、创新性发展。
- **中国革命道德**：全心全意为人民服务、坚定理想信念、勇于牺牲奉献等。
- 革命道德是社会主义道德的**源头活水**。

## 三、社会主义道德

| 要点 | 内容 |
|---|---|
| 核心 | **为人民服务** |
| 原则 | **集体主义**（国家利益、社会利益、个人利益相结合；集体利益高于个人利益） |
| 基本要求 | 爱国守法、明礼诚信、团结友善、勤俭自强、敬业奉献 |
| 落脚点 | 培育和践行社会主义核心价值观 |

## 四、社会公德、职业道德、家庭美德、个人品德

| 领域 | 主要内容 |
|---|---|
| 社会公德 | 文明礼貌、助人为乐、爱护公物、保护环境、遵纪守法 |
| 职业道德 | 爱岗敬业、诚实守信、办事公道、热情服务、奉献社会 |
| 家庭美德 | 尊老爱幼、男女平等、夫妻和睦、勤俭持家、邻里团结 |
| 个人品德 | 勤奋刻苦、诚实守信、正直善良、自律自强 |

## 五、易错提示

- 道德最主要的功能是**调节功能**。
- 社会主义道德的核心是**为人民服务**，原则是**集体主义**。
- 道德与法律的关系：二者都是上层建筑，共同服务于经济基础；道德为法律提供价值基础，法律为道德提供制度保障。
- 诚实守信是职业道德的**核心**（也是社会主义核心价值观个人层面的要求）。
