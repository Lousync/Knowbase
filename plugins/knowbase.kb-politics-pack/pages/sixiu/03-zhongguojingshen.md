# 继承优良传统、弘扬中国精神（中国精神）

> 思修第三章，中国精神、爱国主义是高频考点（含分析题，如"新时代如何弘扬爱国主义"）。

## 一、中国精神

| 要点 | 内容 |
|---|---|
| 内涵 | 以爱国主义为核心的**民族精神** + 以改革创新为核心的**时代精神** |
| 地位 | 中国精神是兴国强国之魂，是民族复兴的精神支撑 |
| 民族精神 | 伟大创造精神、伟大奋斗精神、伟大团结精神、伟大梦想精神 |
| 时代精神 | 改革创新是时代精神的核心，是当代中国最鲜明的精神标识 |

## 二、爱国主义（重点）

### 内涵与基本要求

- **爱国主义**：调节个人与祖国之间关系的道德要求、政治原则和法律规范。
- **基本要求**：爱祖国的大好河山、爱自己的骨肉同胞、爱祖国的灿烂文化、爱自己的国家。

### 新时代爱国主义

| 要点 | 内容 |
|---|---|
| 鲜明主题 | 实现中华民族伟大复兴的中国梦 |
| 本质 | 爱国、爱党、爱社会主义**高度统一** |
| 着力点 | 维护国家统一和民族团结 |
| 重要体现 | 尊重和传承中华民族历史文化 |
| 精神境界 | 胸怀世界、面向未来（构建人类命运共同体） |

## 三、做新时代的忠诚爱国者

- 维护祖国统一、维护民族团结。
- 坚持爱国和爱党、爱社会主义相统一。
- 把爱国主义落实到行动：尊重传承历史、扎根人民、奉献国家。

## 四、易错提示

- 民族精神的核心是**爱国主义**；时代精神的核心是**改革创新**。
- 新时代爱国主义的**本质**：爱国、爱党、爱社会主义的高度统一。
- 爱国主义不是抽象的，是**具体的、历史的**。
- 爱国主义与国际主义、人类命运共同体意识不矛盾。
