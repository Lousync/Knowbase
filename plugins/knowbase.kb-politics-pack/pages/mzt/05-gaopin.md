# 毛中特高频考点与易混对照

> 毛中特选择题"帽子题"集中地，把最常考的对应关系一次理清。

## 一、核心"帽子"对照

| 帽子 | 对应内容 |
|---|---|
| 毛泽东思想**活的灵魂** | 实事求是、群众路线、独立自主 |
| 毛泽东思想的**精髓** | 实事求是 |
| 党的**生命线和根本工作路线** | 群众路线 |
| 新民主主义革命**三大法宝** | 统一战线、武装斗争、党的建设 |
| 中国革命道路 | 农村包围城市、武装夺取政权 |
| 过渡时期总路线 | "一化三改"（工业化为主体） |
| 对资本主义工商业改造的**创举** | 和平赎买 |
| 中特理论体系的**开篇之作** | 邓小平理论 |
| 邓理论**精髓** | 解放思想、实事求是 |
| 党执政兴国的**第一要务** | 发展 |

## 二、易混对照表

| 对比项 | A | B |
|---|---|---|
| 首次提出"马克思主义中国化" | 六届六中全会（1938） | 确立毛泽东思想：七大（1945） |
| 新民主主义革命性质 | 资产阶级民主革命 | 但由无产阶级领导、前途是社会主义 |
| 官僚资本 | 没收 | 民族资本：和平赎买 |
| 社会主义社会矛盾 | 敌我矛盾：对抗性 | 人民内部矛盾：非对抗性（主题） |
| 改革 vs 革命 | 改革是社会主义制度的自我完善 | 社会革命是阶级斗争的最高形式 |

## 三、常考论断速记

- 中国特色社会主义**最本质的特征**：中国共产党领导。
- 中国特色社会主义制度的**最大优势**：中国共产党领导。
- 改革开放是决定当代中国命运的**关键一招**。
- 社会主义基本制度确立：1956 年。
- 我国社会主要矛盾（十九大）：人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。

## 四、易错提示

- "最本质特征"与"最大优势"都是党的领导，但限定词不同（本质特征指中特社义，最大优势指中特社义制度）。
- 改革开放是"关键一招"；全面深化改革是新时代坚持和发展中国特色社会主义的**根本动力**。
- 社会主义初级阶段的**基本路线**："一个中心、两个基本点"。
