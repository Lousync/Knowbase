# 中国特色社会主义理论体系（邓理论/三个代表/科学发展观）

> 毛中特第五至七章。重点：社会主义初级阶段理论、改革开放理论、社会主义市场经济；三个代表、科学发展观的核心观点。

## 一、中国特色社会主义理论体系总论

- **形成背景**：和平与发展成为时代主题，改革开放实践基础。
- **构成**：邓小平理论、"三个代表"重要思想、科学发展观、习近平新时代中国特色社会主义思想。
- **地位**：马克思主义中国化时代化的重要理论成果，党必须长期坚持的指导思想。

## 二、邓小平理论

| 要点 | 内容 |
|---|---|
| 首要的基本理论问题 | 什么是社会主义、怎样建设社会主义 |
| 精髓 | 解放思想、实事求是 |
| 社会主义本质 | 解放和发展生产力，消灭剥削，消除两极分化，最终达到共同富裕 |
| 初级阶段理论 | 我国处于并将长期处于社会主义初级阶段（最大实际） |
| 基本路线 | "一个中心、两个基本点"（经济建设为中心，四项基本原则，改革开放） |
| 社会主义市场经济 | 计划和市场都是经济手段，不是社会主义与资本主义的本质区别 |
| 三步走战略 | 温饱 → 小康 → 基本实现现代化 |
| 历史地位 | 中特理论体系的**开篇之作** |

## 三、"三个代表"重要思想

- **核心观点**：始终代表中国先进生产力的发展要求、中国先进文化的前进方向、中国最广大人民的根本利益。
- **内容**：发展是党执政兴国的**第一要务**；建立社会主义市场经济体制；全面建设小康社会。
- **历史地位**：中特理论体系的丰富发展。

## 四、科学发展观

- **科学内涵**：推动经济社会发展是**第一要义**；**以人为本**是核心立场；**全面协调可持续**是基本要求；**统筹兼顾**是根本方法。
- **历史地位**：中特理论体系在新世纪新阶段的接续发展。

## 五、易错提示

- 邓理论的**精髓**：解放思想、实事求是；**首要的基本问题**：什么是社会主义、怎样建设社会主义。
- 社会主义初级阶段的**主要矛盾**：人民日益增长的美好生活需要与不平衡不充分的发展之间的矛盾（十九大起）。
- 发展是党执政兴国的**第一要务**（三个代表）。
- 科学发展观第一要义是**发展**、核心是**以人为本**。
