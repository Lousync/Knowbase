# 全过程人民民主与全面依法治国

> 新思想第七至九章。全过程人民民主是社会主义民主政治的本质属性；全面依法治国是本质要求和重要保障。

## 一、全过程人民民主

| 要点 | 内容 |
|---|---|
| 本质属性 | 全过程人民民主是社会主义民主政治的**本质属性** |
| 特征 | 全链条、全方位、全覆盖的民主；最广泛、最真实、最管用的民主 |
| 制度载体 | 人民代表大会制度（根本政治制度）、多党合作和政治协商制度、民族区域自治制度、基层群众自治制度 |
| 民主与专政 | 人民民主专政（对人民民主、对敌人专政） |

## 二、全面依法治国

| 要点 | 内容 |
|---|---|
| 地位 | 全面依法治国是中国特色社会主义的**本质要求和重要保障** |
| 总目标 | 建设中国特色社会主义法治体系、建设社会主义法治国家 |
| 基本格局 | 科学立法（前提）、严格执法（关键）、公正司法（防线）、全民守法（基础） |
| 核心要义 | 坚持党的领导、坚持中国特色社会主义制度、贯彻中国特色社会主义法治理论 |
| 依法治国与以德治国 | 相结合（法治与德治相得益彰） |

## 三、中国特色社会主义法治体系

- 完备的法律规范体系（以宪法为核心）
- 高效的法治实施体系
- 严密的法治监督体系
- 有力的法治保障体系

## 四、人民代表大会制度

- 我国的**根本政治制度**（不是基本政治制度）。
- 体现人民主权原则，是实现全过程人民民主的重要制度载体。
- 坚持党的领导、人民当家作主、依法治国**有机统一**。

## 五、易错提示

- 全过程人民民主是社会主义民主政治的**本质属性**（不是"本质特征"——那是党的领导）。
- 人民代表大会制度是**根本政治制度**；多党合作、民族区域自治、基层群众自治是**基本政治制度**。
- 法治运行：立法是前提、执法是关键、司法是防线、守法是基础。
- "依法治国是本质要求和重要保障"——背熟。
