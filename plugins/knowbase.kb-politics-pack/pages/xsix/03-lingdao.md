# 坚持党的全面领导与以人民为中心

> 新思想第三、四章。党的领导是中国特色社会主义最本质特征；人民立场是根本政治立场。

## 一、坚持党的全面领导

| 要点 | 内容 |
|---|---|
| 最本质特征 | 中国共产党领导是中国特色社会主义**最本质的特征** |
| 最大优势 | 中国特色社会主义制度的**最大优势**是中国共产党领导 |
| 最高原则 | **党中央集中统一领导**是党的领导的最高原则 |
| 政治建设 | 党的政治建设是**根本性建设**，首要任务是保证全党服从中央、维护党中央权威和集中统一领导 |
| 全面从严治党 | 新时代党的建设的鲜明主题；自我革命是跳出历史周期率的第二个答案 |

- **党的领导是全面的、系统的、整体的**，体现在党和国家事业各领域各方面各环节。
- 党的领导是做好党和国家各项工作的**根本保证**。

## 二、坚持以人民为中心

| 要点 | 内容 |
|---|---|
| 根本立场 | 人民立场是党的**根本政治立场** |
| 初心使命 | 为中国人民谋幸福、为中华民族谋复兴 |
| 根本宗旨 | 全心全意为人民服务 |
| 群众路线 | 一切为了群众、一切依靠群众、从群众中来到群众中去 |
| 执政理念 | 立党为公、执政为民 |

- **江山就是人民、人民就是江山**：打江山、守江山，守的是人民的心。
- 以人民为中心的发展思想：发展为了人民、发展依靠人民、发展成果由人民共享。

## 三、易错提示

- "最本质特征"（党的领导）与"最本质的属性"（全过程人民民主是社会主义民主政治的本质属性）区分。
- 党的政治建设是**根本性建设**（不是组织建设/思想建设）。
- 党的领导的**最高原则**：党中央集中统一领导。
- 自我革命是跳出历史周期率的**第二个答案**（第一个是让人民来监督政府）。
