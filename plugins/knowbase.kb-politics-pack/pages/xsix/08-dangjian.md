# 全面从严治党与新思想高频考点

> 新思想第十七章 + 全科收尾。党建知识点 + 新思想核心"帽子"汇总。

## 一、全面从严治党

| 要点 | 内容 |
|---|---|
| 战略方针 | 全面从严治党是新时代党的建设的**鲜明主题** |
| 首要任务 | 党的政治建设（**根本性建设**） |
| 制度治党 | 依规治党、制度治党；思想建党和制度治党相结合 |
| 自我革命 | 跳出历史周期率的**第二个答案**；党的自我革命永远在路上 |
| 反腐败 | 一体推进不敢腐、不能腐、不想腐（"三不腐"） |
| 伟大工程 | 党的建设新的伟大工程（党领导的伟大社会革命与自我革命） |

## 二、新思想核心"帽子"汇总

| 帽子 | 对应内容 |
|---|---|
| 最本质的特征 / 最大优势 | 中国共产党领导 |
| 党的领导的最高原则 | 党中央集中统一领导 |
| 首要任务（经济） | 高质量发展是首要任务 |
| 第一动力 | 创新是引领发展的第一动力 |
| 本质要求（共富） | 共同富裕是中国特色社会主义的本质要求 |
| 本质属性（民主） | 全过程人民民主是社会主义民主政治的本质属性 |
| 根本大计（生态） | 生态文明建设是关系中华民族永续发展的根本大计 |
| 总目标（改革） | 完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化 |
| 总目标（法治） | 建设中国特色社会主义法治体系、建设社会主义法治国家 |
| 中国式现代化五大特征 | 人口规模巨大、共同富裕、两个文明协调、人与自然和谐、和平发展 |

## 三、易错提示

- 全面从严治党是**鲜明主题**；自我革命是**第二个答案**。
- 党的政治建设是**根本性建设**，思想建设是**基础性建设**。
- 新思想 = "十个明确" + "十四个坚持" + "十三个方面成就"。
- 世界观方法论"六个必须坚持"：人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。
