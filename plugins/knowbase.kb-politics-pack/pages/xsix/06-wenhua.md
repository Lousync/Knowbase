# 文化强国、民生保障与生态文明

> 新思想第十至十二章。文化自信、共同富裕、双碳目标是高频考点。

## 一、建设社会主义文化强国

| 要点 | 内容 |
|---|---|
| 文化自信 | 更基础、更广泛、更深厚（更基本、更深沉、更持久的力量） |
| 文化根基 | 中华优秀传统文化（创造性转化、创新性发展） |
| 意识形态 | 马克思主义在意识形态领域的**指导地位**（根本制度） |
| 核心价值 | 培育和践行社会主义核心价值观（当代中国精神的集中体现） |

- 文化自信是**最根本的自信**（道路自信、理论自信、制度自信的基础）。

## 二、以保障和改善民生为重点加强社会建设

- **共同富裕**：中国特色社会主义的**本质要求**；中国式现代化的重要特征。
- 收入分配：初次分配、再分配、**第三次分配**（社会公益慈善）。
- 就业优先；健康中国；教育强国；社会保障体系。

## 三、建设社会主义生态文明

| 要点 | 内容 |
|---|---|
| 理念 | 绿水青山就是金山银山（"两山"理念） |
| 定位 | 生态文明建设是关系中华民族永续发展的**根本大计** |
| 目标 | 2030 碳达峰、2060 碳中和（双碳目标） |
| 方针 | 节约优先、保护优先、自然恢复为主 |

- 生态文明是人类文明发展的**历史趋势**，人与自然和谐共生是中国式现代化的重要特征。

## 四、易错提示

- 文化自信是**更基础、更广泛、更深厚**的自信，是**最根本**的自信。
- 共同富裕是**本质要求**，不是同步富裕、不是平均主义。
- 双碳：2030 碳达峰、2060 碳中和（时间不能写反）。
- 生态文明的**基本方针**：节约优先、保护优先、自然恢复为主。
