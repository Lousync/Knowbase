# 新民主主义革命：大革命与土地革命（1919—1937）

> 史纲第二、三章。重点：五四运动、中共成立、大革命、农村包围城市道路。

## 一、五四运动（1919）—— 新民主主义革命的开端

- 导火索：巴黎和会上中国外交失败。
- **意义**：彻底反帝反封建；无产阶级开始登上历史舞台（工人阶级以独立姿态）；促进马克思主义传播与工人运动结合。

## 二、中国共产党成立（1921）

- 中共一大（1921-07）：建党，中心工作组织领导工人运动。
- **意义**："开天辟地的大事变"——中国革命有了坚强的领导核心，中国人民有了主心骨。

## 三、大革命（国民革命，1924—1927）

| 事件 | 要点 |
|---|---|
| 国共第一次合作 | 1924 年国民党一大（新三民主义：联俄联共扶助农工） |
| 北伐战争 | 1926 年，基本推翻北洋军阀统治 |
| 四一二政变 | 1927 年，大革命失败 |

- **大革命失败的教训**：必须坚持无产阶级在统一战线中的领导权；必须建立党领导的人民武装。

## 四、土地革命战争（1927—1937）

| 事件 | 要点 |
|---|---|
| 南昌起义（1927-08） | 打响武装反抗国民党反动派**第一枪**，人民军队诞生 |
| 八七会议（1927） | 确立土地革命和武装反抗国民党的总方针；"枪杆子里面出政权" |
| 秋收起义（1927-09） | 三湾改编（支部建在连上） |
| 井冈山根据地 | 第一个农村革命根据地；**农村包围城市、武装夺取政权**道路开辟 |
| 古田会议（1929） | 思想建党、政治建军 |
| 遵义会议（1935-01） | 生死攸关的转折点；解决军事和组织问题；独立自主解决中国革命问题 |
| 长征（1934—1936） | 三大主力会师；长征是宣言书、宣传队、播种机 |

## 五、易错提示

- 五四运动是新民主主义革命**开端**（分界标志）。
- 南昌起义打响**第一枪**（建军开端）；八七会议确立**总方针**。
- 遵义会议是党历史上**生死攸关的转折点**，是党**第一次独立自主**解决自己的问题。
- 农村包围城市道路的开辟：井冈山时期（《星星之火，可以燎原》）。
