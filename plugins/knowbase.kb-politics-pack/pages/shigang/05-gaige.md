# 改革开放与中国特色社会主义新时代（1978—今）

> 史纲第八至十章。重点：十一届三中全会、改革开放、新时代成就、中国式现代化。

## 一、改革开放的伟大转折

- **十一届三中全会（1978-12）**：确立解放思想、实事求是的思想路线；把工作重心转移到经济建设上来；作出改革开放的历史性决策。**伟大转折**。
- **改革首先从农村突破**：家庭联产承包责任制（小岗村）；随后城市经济体制改革。
- **对外开放格局**：经济特区（深圳等）→ 沿海开放城市 → 沿江沿边 → 全方位多层次宽领域。

## 二、中国特色社会主义的开创与发展

| 会议 | 内容 |
|---|---|
| 十二大（1982） | 提出"建设有中国特色的社会主义" |
| 十三大（1987） | 社会主义初级阶段理论；基本路线；三步走 |
| 南方谈话（1992） | 计划和市场都是手段；社会主义本质论 |
| 十四大（1992） | 建立社会主义市场经济体制 |
| 十五大（1997） | 邓小平理论写入党章 |
| 十六大（2002） | "三个代表"写入党章 |
| 十七大（2007） | 科学发展观写入党章；中国特色社会主义理论体系 |
| 十八大（2012） | 进入新时代；"五位一体" |

## 三、新时代的历史性成就

- 打赢脱贫攻坚战，全面建成小康社会（2021 宣告）。
- 建党百年（2021）："两个确立"；党的百年奋斗的**三大历史决议**（第三个：《关于党的百年奋斗重大成就和历史经验的决议》）。
- 二十大（2022）：中国式现代化；两步走战略。

## 四、改革开放的意义与经验

- 改革开放是决定当代中国命运的**关键一招**，是当代中国最鲜明的特色。
- 经验：坚持党的领导；坚持走中国特色社会主义道路；坚持人民主体地位；坚持完善和发展中国特色社会主义制度。

## 五、易错提示

- 改革开放**开端**：十一届三中全会（1978）。
- "建设有中国特色的社会主义"首次提出：十二大（1982）。
- 新时代**进入标志**：十八大（2012）。
- 党的历史上三个历史决议：1945 年六届七中全会、1981 年十一届六中全会、2021 年十九届六中全会。
