# 抗日战争与解放战争（1937—1949）

> 史纲第四、五章。重点：抗战中流砥柱作用、党的七大、两个中国之命运、七届二中全会。

## 一、抗日战争（1937—1945）

| 事件 | 要点 |
|---|---|
| 九一八事变（1931） | 局部抗战开始；东北抗联 |
| 七七事变（1937） | 全面抗战爆发；第二次国共合作形成 |
| 洛川会议（1937） | 全面抗战路线（人民战争路线） |
| 平型关大捷、百团大战 | 敌后战场战绩 |
| 中共七大（1945） | 毛泽东思想写入党章；三大作风 |
| 抗战胜利（1945） | 近代以来第一次**完全胜利**的民族解放战争 |

- **中国共产党是抗日战争的中流砥柱**：坚持全面抗战路线；倡导抗日民族统一战线；领导敌后战场（抗战后期成为**主战场**）。
- 抗战胜利的意义：捍卫国家主权领土完整；促进民族觉醒；为世界反法西斯战争作出重大贡献。

## 二、解放战争（1946—1949）

| 阶段 | 要点 |
|---|---|
| 争取和平民主 | 重庆谈判（《双十协定》）；政治协商会议 |
| 战略防御/反攻 | 1947 年刘邓大军挺进大别山，转入战略进攻 |
| 三大战役 | 辽沈、淮海、平津（1948—1949），基本消灭国民党军队主力 |
| 渡江战役 | 1949-04，占领南京，国民党统治覆灭 |

- **《中国土地法大纲》（1947）**：实行耕者有其田，废除封建剥削土地制度。
- **七届二中全会（1949-03）**：工作重心乡村→城市；"两个务必"；中国从农业国向工业国转变。

## 三、两个中国之命运

- 国民党代表的大地主大资产阶级专政（独裁内战）vs 共产党主张的人民民主专政（和平民主建国）。
- 人民政协《共同纲领》（1949-09）：起临时宪法作用。

## 四、新民主主义革命胜利的意义

- 结束帝国主义列强压迫中国、奴役中国人民的历史；结束半殖民地半封建社会。
- 新中国的成立：中国历史新纪元，民族独立和人民解放基本实现。

## 五、易错提示

- 抗战胜利是近代以来**第一次完全胜利**的民族解放战争。
- 中共七大确立毛泽东思想为**指导思想**（写入党章）。
- "两个务必"：七届二中全会（谦虚谨慎不骄不躁、艰苦奋斗）。
- 抗战胜利后中国社会主要矛盾：人民大众与美帝国主义支持的国民党反动派之间的矛盾。
