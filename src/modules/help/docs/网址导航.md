把学习资料网址集中管理:分类保存、一键跳转、搜索,并支持与浏览器互通的导入导出。

## 分类与书签

- 左侧分类栏内置「**全部书签**」与「**未分类**」,自定义分类带 10 色圆点标识,可随时编辑 / 删除
- 书签以卡片网格展示:域名首字母彩色头像 + 标题 + 域名 + 描述
- **点击卡片**即打开网页;悬停卡片浮现操作条:打开 / 复制链接 / 编辑 / 删除

添加书签时:

- 标题与网址必填;网址自动补 `https://`,格式错误会实时红字提示
- 描述可选;在某个分类视图下点「添加书签」会自动预选该分类

## 搜索

顶部搜索匹配**标题 / 网址 / 描述**,范围限定当前选中的分类,旁侧显示命中数量。

## 导入与导出

| 格式 | 用途 | 说明 |
|------|------|------|
| JSON | 完整备份 | 含分类(名称、颜色)与全部书签,可再导入本应用 |
| HTML | 导入浏览器 | Netscape 书签格式,分类导出为文件夹,**可直接导入 Chrome / Edge / Firefox** |

**导入规则**(仅接受本应用导出的 JSON):分类按名称合并去重;书签按网址去重,重复的自动跳过,完成后汇总提示新增与跳过数量。

> 删除分类时,其中书签会自动移入「未分类」,不会丢失。
