用**多系列折线图**记录体重变化,支持多组数据同图对比、自由缩放与横滚浏览。

## 记录体重

点击右上角「＋ 记录」打开录入弹窗:

- **体重**:必填,须大于 0;输入框内按 `Enter` 直接保存
- **日期**:默认当天,可改历史日期
- **系列**:下拉选择已有系列,或在「新系列名」中创建新系列(如「晨重」「晚重」)
- **备注**:可选

## 图表交互

| 操作 | 效果 |
|------|------|
| 滚轮 | 缩放 X 轴(相邻点间距) |
| `Ctrl` + 滚轮 | 缩放 Y 轴 |
| 悬停数据点 | 显示数值、日期、系列、备注 |
| 点击数据点 | 选中后在顶栏出现编辑 / 删除操作条 |

- 每个系列自动分配固定颜色,点击顶部系列色块可**显示 / 隐藏**该系列(至少保留一个)
- 数据点多时画布自动加宽,可**横向滚动**;缩放状态可一键重置
- 单位支持 **kg / 斤** 切换(仅影响显示,内部统一以 kg 存储)

## 记录列表

图表下方按系列分组列出所有记录,分组可折叠;每行可直接编辑或删除,点击某行也会在图上选中对应数据点(双向联动)。

> 删除记录为**永久删除**,不进入回收站,请谨慎操作。
