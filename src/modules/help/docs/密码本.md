集中保存网站 / 应用的账号密码,支持快速搜索、一键复制,配合全局**快速填充悬浮窗**在其他应用登录时取用。

## 条目字段

点击「＋ 新建」创建条目(名称必填),详情面板中可维护:

| 字段 | 说明 |
|------|------|
| 名称 | 网站 / 应用名 |
| 账号 | 登录用的邮箱 / 手机号 |
| 用户名 | 显示名称(与账号是两个独立字段) |
| 密码 | 默认掩码显示,点击掩码框即显示明文并全选,也可用眼睛按钮切换 |
| 网址 | 可一键在系统浏览器打开(自动补 `https://`) |
| 备注 | 自由文本 |

编辑**自动保存**:修改后约 1 秒自动写库,切换条目时未保存的修改也会立即提交;顶部指示灯显示保存状态(黄点未保存 / 绿点已保存)。

## 复制与安全

- 复制账号 / 用户名后按钮变对勾反馈
- **复制密码后 30 秒自动清空剪贴板**
- 所有数据仅保存在本机数据库中,请确保操作系统账户安全,不要外传数据库文件

## 搜索与删除

- 顶部搜索匹配**名称 / 账号 / 用户名 / 网址**四个字段
- 列表条目**右键**可直接删除;删除会**移入回收站**,可在「回收站」模块恢复

## 快速填充悬浮窗

在任意应用登录时,按全局快捷键 `Ctrl` `Alt` `P` 呼出置顶小窗(不抢焦点):

- 输入关键字搜索,`↑` `↓` 选择条目
- 一键复制账号 / 用户名 / 密码
- `Esc` 清空搜索或隐藏窗口,再次按 `Ctrl` `Alt` `P` 也可隐藏
