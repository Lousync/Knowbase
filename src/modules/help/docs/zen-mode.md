# 禅模式

写作态专注模式：隐藏一切外围 UI，只留正在写的文字。作用于编辑器模块，与「沉浸阅读」（阅读态）对称。

## 快捷键

- **Ctrl+K 然后 Z**：循环切档 —— 关闭 → Z1 专注 → Z2 禅 → 关闭
- **Esc**：退出禅模式（有弹窗时先关弹窗，再按一次 Esc 才退出）
- 切换到其他模块会自动退出禅模式

## 三档说明

- **Z1 专注**：隐藏文件树、标签栏、状态栏，正文限宽居中（宽度可在设置调整）
- **Z2 禅**：在 Z1 基础上隐藏标题栏与活动栏，窗口全屏留白。鼠标移到屏幕顶部可唤出控制条（可拖动窗口、最小化/最大化/关闭、降档、退出）

## 悬浮信息条

右下角极轻文字显示 **字数 · 保存状态**，30 秒无操作自动淡出，移动鼠标或键入即唤醒。禅模式内保存（Ctrl+S）不会弹出提示，右下角会短暂显示「已保存 HH:MM」。

## 设置

设置 → 通用 → 外壳：

- **禅模式正文宽度**：限宽像素（600-1400，默认 860）
- **禅模式字数统计**：是否在信息条显示字数

> 字数口径：中文按字符计、英文按单词计；文件头元数据（frontmatter）不计入。
