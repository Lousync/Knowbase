生成高强度随机密码。使用 Web Crypto API 的**密码学安全随机数**(非普通伪随机),并保证每种已选字符类型至少出现一次。

## 生成设置

- **长度**:滑块调节 4 ~ 64 位,或用快捷按钮直接选 12 / 16 / 24 / 32 位
- **字符类型**(可多选,不允许全部关闭):
  - 小写字母(a-z)
  - 大写字母(A-Z)
  - 数字(0-9)
  - 特殊符号(`!@#$%^&*()-_=+[]{}:,.?`)

## 强度评估

生成后密码框下方显示强度条与分级:**弱 / 一般 / 强 / 极强**——长度越长、字符类型越多,强度越高。

## 使用建议

- 点击「生成」产出新密码,点密码框右侧按钮复制
- 修改长度或字符类型会**立即清空旧密码**,避免误复制过时密码
- 生成的密码**不保存任何历史记录**,请生成后立即复制并妥善保存
- 一般建议:长度 ≥ 16 且包含全部四类字符
