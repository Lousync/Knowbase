# Knowbase Web Clipper（浏览器扩展）

把浏览器里看到的好文章**一键剪藏**进本地 Knowbase 仓库。全程只走 `127.0.0.1`，内容不出你的设备。

## 安装（开发者模式加载，未上架商店）

1. 打开 Knowbase 桌面端 → 工具箱 → **网页剪藏**，复制「扩展目录」路径
2. Chrome / Edge / Brave 地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 开启右上角 **开发者模式**
4. 点 **加载已解压的扩展程序**，粘贴第 1 步复制的目录
5. 回到 Knowbase 剪藏面板复制 **配对令牌**，点扩展图标 → 粘贴令牌 → 配对

## 使用

- **剪藏整页**：提取正文转 Markdown，存入 `<仓库>/.knowbase/_draft/clipper/<日期>-<标题>.md`
- **仅存链接**：只要标题和 URL（SPA/登录墙页面会自动降级到这一档）
- 剪藏产物是**草稿**：不带 frontmatter id，不进知识库列表/图谱；用编辑器整理后补 `id:` 并移入分类即"转正"
- 桌面端切换仓库后，下一次剪藏自动落新仓库（无需重配）

## 常见问题

| 现象 | 处理 |
|---|---|
| 「未连接」灰点 | 桌面端没开（服务随应用启动） |
| 端口漂移连不上 | 扩展自动探测 42817–42824；面板会显示实际端口 |
| 「令牌无效」 | 桌面端重置过令牌 → 重新复制粘贴 |
| 「桌面端未打开仓库」 | 先在 Knowbase 里打开任一仓库 |
